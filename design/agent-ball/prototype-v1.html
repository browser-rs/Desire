对比与建议

方向 心智原型 优势 风险 / 代价
V1 珠与牋 现有形态的精修 改动最小；菜单头带页面上下文；拖动/吸附逻辑完全复用 形态上没有惊喜，仍是"球+列表"
V2 灵动岛 主推 Dynamic Island 变形胶囊 状态全部可见（待命/处理/声纹/已回复）；热区大；最具 iPhone 质感；录音态天然出彩 吸附时 470pt 宽岛需限宽/收窄排布；拖动手感要重新调
V3 辅佐触盘 iOS AssistiveTouch 圆盘 按钮大、盲点得中；弹出动画最有"被伺候"感 占屏幕面积大；信息承载弱（放不下上下文/状态文案）

推荐：V2 为主体，吸收 V1 的菜单头。即"胶囊岛展开后，左端是页面上下文与状态，右端是大热区动作"。三个方向的状态语义（呼吸/外环/声纹/绿徽章）通用，选定形态后原样移植到原生 glassEffect 实现里。

实现注记 · 真机材质 = .glassEffect(.regular.interactive(), in: .circle / .capsule / .rect(cornerRadius:))（窗口内 overlay，已验证真折射）；朱砂 = 应用强调色跟随；动效全用 spring（response 0.3–0.5）；拖动/吸附/持久化沿用现有实现不动。尺寸档位（44/52/60）三个方向都保留。
