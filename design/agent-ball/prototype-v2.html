悬浮球 v5 · 展开动画与功能扩充 原型 v2

三个展开动画方向（A 绽放 / B 液态形变 / C 轨道汇聚）+ 四项功能扩充。 每个舞台里的球都真的能点：点球展开、点 ✕ 或点空白收起、悬停看微交互。 玻璃材质为 CSS 模拟，真机映射原生 .glassEffect。评审拍板后再写 SwiftUI。

方向 A · 绽放 Bloom — 盘从球心弹性放大，格子向外弹出 + 一次性掠光

球先轻微下压（蓄力），触盘从球的位置放大弹出；四格依次向外弹出带过冲，开盘瞬间一道玻璃掠光。收起 = 逆向快速合拢。

方向 B · 液态形变 Morph — 球本身被拉开成触盘，背景渐进聚焦压暗

不弹出新盘：球在原地被"拉开"——先变宽、慢半拍变高（液态拉伸），圆→圆角矩形，格子在盘内从模糊中浮起；页面背景同时模糊压暗（聚焦感）。收起 = 先收高再收宽。

方向 C · 轨道汇聚 Orbit — 格子沿弧线旋入，盘面带 -7°→0° 的落定旋转，悬停视差

开盘前一道虚线轨道闪现（AssistiveTouch 语汇），格子带着 38° 自旋沿弧线汇聚落位，盘面反向微旋对齐。悬停某格时整盘向该格方向轻微倾斜（视差）。

三方向对比与 SwiftUI 实现映射

A 绽放 BloomB 液态形变 MorphC 轨道汇聚 Orbit
气质轻快、直给，AssistiveTouch 正统续作最"液态玻璃"，系统级质感最有仪式感，动势最强
总时长≈0.55s≈0.55s（液态两段）≈0.7s（含轨道闪现）
SwiftUI 实现scaleEffect + delayed spring + 掩模渐变掠光——全是现有积木matchedGeometryEffect + 两段式尺寸 + 背景模糊层rotationEffect 弧线入位 + rotation3DEffect 视差
风险低 纯组合中 玻璃形变中间态需真机验证（NSGlassEffectView 对 morph 的支持未知）中 视差跟踪需手势/悬停坐标，弧线语义在 2×2 网格上稍弱
与现有代码距离最近（V3 弹入的加强版）中（开合路径重构）中
我的推荐：A 为主干（低风险、与 V3 定稿语言一脉相承），吸收 B 的「背景聚焦压暗」与 C 的「悬停视差」作为全局微交互；功能四项全做（①②③④ 与方向正交）。 你拍板：单选 A/B/C，或"组合 D"（A + 压暗 + 视差）。
