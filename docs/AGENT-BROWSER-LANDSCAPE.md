# Agent 浏览器做法对照与优化清单（2026-10-30）

**资料范围**：本轮能抓到的只有开源 agent 浏览器/自动化框架的 README（官方产品帮助页在本机网络下
不可达）；以下归纳"做法"，不列出处。结论只用于设计取舍，不当作产品宣传。

## 一、反复出现的四类做法

1. **会话连续性优先**：把"登录一次、长期有效"当第一体验——持久档案/会话目录，重启仍在；
   跨设备只迁 cookie（localStorage/IndexedDB 不迁），并明确告知部分站点仍需重登。
2. **隔离分档**：持久档案（单写者，同一时刻只能一个实例）／临时会话（内存，任务级隔离，
   可用种子登录态）／借用现有浏览器（登录态最强、隔离最弱）。并行任务必须各占一档。
3. **贴着浏览器做控制**：扩展/进程内直连以降低每次动作的往返；页面侧只取结构化观测
   （可见文本/可交互元素），不把整页 DOM 塞给模型。
4. **看—做—验闭环**：动作后立刻核验（元素是否出现、页面是否变化、截图是否一致），
   失败就换策略；人类接管（登录/验证码/确认）是一等公民，接管期间自动化让路。

## 二、Desire 现状对照

- 已有：三模式（工作台/纯浏览器/混合）、持久 Agent 容器与临时读、cookies 快照、
  Peek 接管锁、逐回合工作自述与失败分类、轨迹页、结构化提取（表格/评论/对话/元信息）。
- 缺口（按价值排序）：
  - **动作后没有机械核验**：`verificationNote` 靠模型自觉；副作用动作缺少"前后对比"。
  - **接管锁是整面级**：用户在面板里看一个标签，Agent 连其他标签也不能动。
  - **容器登录态是空白起点**：首次用 Agent 窗口访问需要登录的站点时没有引导。
  - **观测重复**：连续动作各自取一次 DOM/快照，往返多、模型上下文里也重复。
  - **并行隔离粒度**：crew 是整组一个临时容器，worker 之间共享 cookie。
  - **接管期间的用户操作不可回放**：交还时只说"页面变了"，说不出变了什么。

## 三、优化清单（建议进 v0.8.25）

**P0**

1. **动作后自动核验**：对 click/type/submit 等副作用动作，自动做「动作前快照 → 动作 →
   等待稳定（≤2s）→ 快照对比」；结果写进工具观察与轨迹（`verified / unchanged / diverged`），
   失败步骤给模型明确信号。截图取缩略尺寸，仅在差异可疑时取全图。
2. **按标签的接管锁**：锁从 TabManager 粒度下沉到 Tab 粒度——用户接管某标签时，Agent
   仍可操作同一窗口的其他标签；Peek 浮层显示"正在接管哪一页"。
3. **Agent 登录态引导**：首次在 Agent 窗口遇到登录页/登录表单时，主动提示
   "导入当前 cookies / 在此登录一次"二选一（导入走 `/cookies/seed`，并写明限制）。

**P1**

4. **观测缓存（observe once, act many）**：一轮工具序列内复用同一份页面观测与元素引用，
   只在导航/DOM 变更时失效；减少往返与上下文重复。
5. **worker 级隔离**：`crewDispatch` 支持每个 worker 独立临时会话（`isolation=worker-ephemeral`），
   与整组隔离并存；回执标注隔离级别。
6. **面板会话续跑**：专注面板的标签在重启后恢复选中页与滚动位置（SavedTab 已有
   `sessionState`，补面板管理器的恢复路径）。
7. **接管回放摘要**：用户接管期间记录"点击/输入/跳转"的**去敏**摘要（选择器 + 动作 +
   标题），交还时作为备注给 Agent（不记输入值）。
8. **Peek 快捷动作**：浮层直接给"允许/拒绝/重试"三个按钮，减少一次窗口切换。

**P2**

9. **站点级 Agent 偏好**：按 host 记录"允许自动操作/始终用隔离容器/需要确认"，
   与现有站点权限面合并。
10. **失败步骤一键重跑**：轨迹页对失败步骤提供"只重跑这一步"（沿用工具参数），
    成功后继续回合。
11. **隔离默认值的首启引导**：首次进入专注/混合时询问"隔离 or 沿用登录态"，
    按选择写默认值（已有一次性说明，补选择）。
12. **观测节流**：面板折叠/窗口不可见时，缩略图与快照降到 10s 或暂停；恢复可见再刷新。

## 四、明确不做

- 云端/虚拟机浏览器；跨窗口搬 webview；按站点混合登录态；把整页 DOM 塞模型的"视觉大模型"
  路线（我们走结构化观测）。
