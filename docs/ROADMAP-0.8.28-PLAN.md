# v0.8.28 规划稿（2026-10-31，待过目）—— 剪辑工作台收口 + 播放器闭环

> 前置：v0.8.27 待发（内容已很厚：desire:// 体系 + 59 工具 + 媒体剪辑三批 +
> 播放器三批）。本稿是**下一版**，不是 0.8.27 的追加——先发 27 再动工。
> 主题四线（浏览器基础 / Agent 基础 / 融合 / 替人干活）里本版偏**融合**：
> 把 0.8.27 攒出的媒体能力从"能用"打磨成"顺手"。

## 一、剪辑工作台收口（8 项）

1. **多选交互**（P1）：时间线 ⌘/⇧ 点选多片段，框选；批量删除/移动/静音
   （逻辑已就位：`deleteClips(ids:)`，补 UI 与选择状态）。
2. **源监视器**（P1）：素材池条目双击弹预览（播放+入出点修剪），"插入"把
   修剪后的段落到播放头——素材先行筛选再上轨（剪映/Pr 的核心手感）。
3. **轨道头操作**（P2）：静音/隐藏整轨、轨道高度记忆、拖拽排序轨道。
4. **关键帧音量**（P2，视工作量裁剪）：片段内音量包络点（至少 3-5 个点），
   替代整段单一增益。
5. **贴齐**（P1）：片段拖移吸附播放头/相邻片段边缘/秒刻度（阈值 8px），
   按住 ⌘ 临时禁用——没有贴齐的多轨时间线很难剪齐。
6. **导出预设**（P2）：分辨率（1080p/720p/源）× 码率档（高/中/低）+
   仅音频导出（m4a/mp3）+ 导出后"在 Finder 中显示"已有，补"直接发起新回合
   交给 Agent 处理"（融合线：剪完即交 Agent 上传/转格式）。
7. **历史面板**（P2）：撤销栈可视化（跳回任意一步），对齐图片编辑器的历史面板。
8. **键盘完备**（P2）：S=分割、Delete=删除、⌘Z=撤销、空格=播放、⌘A=全选、
   +/-=缩放、Home/End=跳首尾——时间线聚焦时的键位表。

## 二、播放器闭环（4 项）

9. **字幕样式**（P2）：字号/描边/位置（底/中/顶）设置，按文件记忆。
10. **字幕延迟**（P2）：⌘[ / ⌘] 微调 ±0.5s（字幕与音轨不同步的现场急救）。
11. **AB 循环**（P3）：入点 A/出点 B 区间循环（学语言/看教程刚需）。
12. **截图**（P2）：H 键截当前帧进剪贴板/图片编辑器（与剪辑工作台联动）。

## 三、浏览器与 Agent 常规（4 项）

13. **desire://tools 搜索直达**（P3）：地址栏输入工具名即建议并深链（补全
    desire:// 体系的发现面）。
14. **媒体文件右键菜单**（P2）：查看器/时间线右键"用 Desire 剪辑/提取音轨/
    转格式"——把 0.8.27 的能力补上入口面。
15. **Agent 工具接入剪辑**（P1）：`editTimeline` 工具（建工程/插片段/设入出点/
    导出），让"帮我把这个视频剪成三段"真正跑通——媒体批的 Agent 化收口。
16. **发布页/产品页更新**（P2）：工具箱 59→60+、剪辑工作台、播放器截图与文案。

## 不做（本版明确）

- 多机位/色度键/曲线变速——超出"内置剪辑"定位，剪映级专业功能不追。
- 关键帧动画（画面 transform 的）——音量包络先验证需求。
- 内置 ffmpeg——既有立场不变。

## 批次

① 1+5+8（多选/贴齐/键盘——时间线手感三件套）→ ② 2+15（源监视器 + Agent 工具）
→ ③ 6+14+16（导出预设/右键入口/产品页）→ ④ 3+4+7+9~12+13（收口与播放器小件）。

harness 全绿（新纯逻辑：贴齐数学/包络插值/AB 循环状态机）、clean 零警告、
