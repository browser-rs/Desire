# v0.8.30 规划稿（2026-10-31，待过目）—— 媒体工作台收口 + 媒体 Agent 工具族

> 0.8.27→29 三连版把剪辑工作台从零堆到多轨专业形态；本版**收尾媒体主线**，
> 把「能剪」变「好看好感知」：波形可视化、播放列表、Agent 媒体感知工具族，
> 并把媒体能力接回浏览器右键面（融合线）。规划前已核实四项候选全部未做。

## 一、媒体工作台收口（4 项）

1. **音频波形渲染**（P1 旗舰）：AVAssetReader 采样 min/max 列，音频轨片段
   画真实波形（替代纯色块）；按 (文件, 采样宽) 缓存、后台 Task 采样不卡时间线；
   源监视器也画。
2. **播放列表**（P2）：播放器支持多文件顺序播放（素材池「加入队列」+ 拖入多个），
   上一/下一曲、列表循环/单曲循环；队列会话内有效（不持久，诚实口径）。
3. **analyzeMedia Agent 工具**（P1）：ffprobe JSON（时长/容器/编码/分辨率/
   轨道清单/码率）——editTimeline 的前置决策工具，「这个视频什么规格」一句话可答。
4. **导出历史**（P3）：本次会话导出列表（产物名 + 直达 Finder），对齐下载中心体感。

## 二、媒体 × 浏览器融合（2 项）

5. **网页视频右键 → 剪辑**：嗅探到的媒体（detectedMedia）右键菜单加
   「下载并剪辑此视频」——下载完成自动进时间线，浏览器到剪辑一条链。
6. **listDetectedMedia Agent 工具**（P1）：把嗅探到的页面媒体暴露给智能体——
   「把刚才那个视频下载并剪掉前 30 秒」全链路一句话（下载工具已有，
   与 editTimeline/analyzeMedia 组成媒体工具族三件套）。

## 三、发布面（2 项）

7. **发布页截图素材**：多轨编辑器（带波形）/播放器各一张——桥/离屏快照产出。
8. **产品页文案**：媒体工具族 + 波形（发版冻结时做，既定纪律）。

## 不做（本版明确）

- 波形**编辑**（拖波幅改增益）——v1 只读渲染，编辑走包络。
- 播放列表跨会话持久——会话内有效，不装深度。
- 多机位/色度键/内置 ffmpeg——立场不变。

## 批次

① 1 波形 + 3 analyzeMedia（看得见 + 答得出）→ ② 2 播放列表 + 6 listDetectedMedia
→ ③ 5 右键入口 + 4 导出历史 + 7/8 发布面（发版冻结一起）。
