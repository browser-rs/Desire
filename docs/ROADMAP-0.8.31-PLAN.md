## 一、浏览器日常（4 项）

1. **图片右键 → 反向搜索**（P1）：右键图片按所选引擎反搜——Google Lens /
   Bing Visual / Yandex / SauceNAO（设置页引擎开关，默认 Lens）。
2. **图片右键 → 用 Desire 编辑**（P1）：右键图片下载进图片编辑器
   （0.8.12 的编辑器一直缺浏览器入口面）；下载沿用媒体管线（带 referer）。
3. **链接右键 → 复制为 Markdown**（P2）：`[文本](URL)` 进剪贴板；
   选区右键 → `[选区文本](链接地址)`。
4. **地址栏多行粘贴批量打开**（P2）：粘贴含多行 URL 的文本 → 询问
   「打开全部 N 个标签？」（≥2 行才触发；每行先归一化补 scheme）。

## 二、Agent 会话打磨（2 项）

5. **消息编辑重发**（P1）：最后一条用户消息可编辑后重跑（改问题不再只能
   regenerate 原样重试）；编辑走原消息替换 + 其后消息裁剪，轨迹留 edit 标记。
6. **工具卡批量折叠**（P3）：回合内连续 3+ 个同工具的调用折叠为
   「readFile ×5」一行，点开展开——长回合轨迹可读性。
