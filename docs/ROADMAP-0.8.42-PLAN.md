### A3. 透视校正

- 四角拖拽 → 单应性变换矫正（CoreImage CIPerspectiveCorrection）；
  参考网格 overlay；应用 = 烙图（可撤销）。

### A4. 性能与快捷键

- 大图（≥30MP）：打开时降采样到编辑分辨率（记录源尺寸）；
  导出面板可选”按原图尺寸重渲”。
- 快捷键：V 选择/M 马赛克/L 套索/W 魔棒/B 画笔/E 橡皮（=清选区）/
  ⌘⇧E 导出/空格临时原图/⌘D 复制图层；快捷键面板列出。
- 验收：30MP 打开 <2s、编辑不掉帧、导出可选原图尺寸；快捷键全流程可用。

## 二.5、增补项（用户提出”再丰富一下”）

### A5. Before/After 对比滑杆

- 可拖拽分割线（左右对比）：左侧 = 原图，右侧 = 当前渲染结果。
- 拖拽手柄可视化（竖线 + 圆形手柄）；非全屏也可用。
- 键盘快捷键 `\` 临时 50/50 对比；松开恢复。

### A6. 裁剪预设（社交尺寸）

- 预设列表：Instagram Post 1:1、Story 9:16、YouTube Thumbnail 16:9、
  Facebook Cover、Twitter Header、小红书 3:4、微信公众号封面 2.35:1。
- 裁剪模式下预设按钮行（与比例锁定并列）；选中即锁比例 + 可选”居中裁切”。

### A7. 编辑快照持久化

- 保存文档时同步写入管线快照 JSON（`<file>.editstate.json`）。
- 重新打开同一文件时恢复管线（undo 栈/redo 栈/选区/图层）——做到
  “关闭重开还能继续编辑”（当前只保留烙图结果）。
- 删除快照文件 = 丢弃编辑状态（编辑器 Back 时提示）。

### A8. 批量水印

- 对文件夹内全部图片应用同一水印参数（文字/图片），写入 `Watermarked/`。
- 走 Job 队列（取消/进度/失败逐项）；Agent 工具 `batchWatermarkImages`。

### A9. 拼图合成

- 两张图水平/垂直拼接（对齐边、留 gap 可调）；输出到 `Merged/`。
- Agent 工具 `mergeImages(paths[], direction, gap)`。

### A10. 颜色取样器

- 按住 ⌥ 点击画布 → 取样颜色显示在工具栏（hex + RGB）；点击复制 hex。
