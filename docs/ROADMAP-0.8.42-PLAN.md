## 二、Track A：编辑器收尾

### A1. EXIF 查看/编辑

- 读取：EXIF/DICOM/XMP 摘要（相机型号/镜头/参数/时间/GPS/方向/版权）；
  面板按组展示，只读。
- 编辑：标题/作者/版权/描述/关键字；GPS 清除（一键，不可逆——confirm）；全清除。
- 写入：CGImageSource/CGImageDestination 复制属性（不重编码像素）。
- 导出面板复用：勾选“保留 EXIF”/“清除 GPS”/“剥离全部”。
- 验收：有 GPS 的照片 → 清除 GPS → 导出后不含坐标；标题/作者写入正确；
  像素不重压缩（字节长度接近原文件）。

### A2. 水印

- 文字水印：内容/字体大小/颜色/透明度/位置（九宫格 + 边距）/旋转；平铺模式。
- 图片水印：PNG（含透明）+ 缩放/位置/透明度/旋转/平铺。
- 保存为预设（与编辑预设同一 store，`watermark` 字段）；导出面板与 Agent 工具共用。
- 验收：文字/图片水印在九宫格各角落 + 平铺全覆盖，透明度正确；保存预设后跨文档复用。

### A3. 透视校正

- 四角拖拽 → 单应性变换矫正（CoreImage CIPerspectiveCorrection）；
  参考网格 overlay；应用 = 烙图（可撤销）。
- 验收：斜拍文件/白板 → 拖四角 → 输出正面视角；无黑角。

### A4. 性能与快捷键

- 大图（≥30MP）：打开时降采样到编辑分辨率（记录源尺寸）；
  导出面板可选“按原图尺寸重渲”（放大管线操作坐标）。
- 快捷键：V 选择/M 马赛克/L 套索/W 魔棒/B 画笔/E 橡皮（=清选区）/
  ⌘⇧E 导出/空格临时原图/⌘D 复制图层；快捷键面板列出。
- 验收：30MP 打开 <2s、编辑不掉帧、导出可选原图尺寸；快捷键全流程可用。

## 三、Track B：四主题常规细节

### B1（①基础）大图护栏

- 编辑分辨率上限 8192px 长边（超出自动降采样，状态条提示“编辑分辨率 xxx，
  导出可选原图尺寸”）；tile 渲染不必做——CI 自动 tile。
- 内存护栏：连续操作超过 6 步时自动释放中间历史位图（只留管线快照）。

### B2（②Agent）编辑器工具族

- `imageInfo(path)`：尺寸/格式/EXIF 摘要/体积。
- `setImageWatermark(path, text|image, position, opacity, tile)`：返回输出路径。
- `straightenImage(path, degrees)`。
- `autoEnhanceImage(path)`：AI 自动增强（直接调 `ImageAICore.autoEnhance`）。
- 全部走 Agent 工作区路径校验，返回输出路径。

### B3（③融合）编辑完成回 Remote

- 编辑器保存/导出后可选“发送到手机”（复用 `sendToPhone` 帧，kind=edited）。

### B4（④替人干活）水印/EXIF 一键

- 工具箱新增「图片水印」「EXIF 清除」卡片（非 Agent 也可用）。

## 六、不做

- 通道级调色（曲线分通道已够用）。
- 批量透视校正（体量大、场景少）。
