## 为什么是它

1. **书签栏是单层的**：`BookmarksBarView` 文件夹只渲染一层子项（面板里明明
   有整棵树）；不能拖拽排序（只能去面板里挪）、文件夹不能"打开全部"、
   中键没有后台打开——Chrome/Safari 用户第一天就会撞上的手感差。
2. **右键菜单差两件**：Download Linked File（链接另存为下载）与 Copy Link
   Text（复制链接文字）。下载引擎其实**已经存在**（`downloadFile` 工具的
   台账式传输：暂停/恢复/进度），右键只是没有入口——纯接线活。
3. **"发送到"没有推广**：0.8.52 给工具结果卡做了 白板/摘录/Markdown 分发条，
   但历史行、下载行、书签行这些"天然的收藏候选地"反而没有同样的动作。

## 旗舰（P0，浏览器基础）：书签 2.0

### 1. 书签栏升级

- **多级文件夹**：栏上文件夹渲染整棵子树（递归子菜单，面板同源）；
- **拖拽排序**：栏内拖拽重排 + 拖入/拖出文件夹（持久化走 BookmarkStore 既有
  移动 API；跨窗口拖拽暂不做）；
- **打开全部**：文件夹右键"打开全部（N）"，超 8 个走确认；
- **中键后台打开**：书签/文件夹项中键 = 后台标签打开（与标签栏中键关闭同款
  事件监视路径）；
- **溢出**：栏宽不够时收进「⌄ 更多」。

### 2. 书签面板整理增强

- 面板树支持拖拽移动（跨文件夹/调序）；
- 多选批量"移入文件夹"（复用批量编辑的既有选择模型）。

## 四主题常规

### ① 浏览器基础（第二件）：右键补齐

- **Download Linked File**：链接右键 → 复用 `downloadFile` 的台账式下载
  （进下载面板：暂停/恢复/进度/通知全复用；文件名冲突走既有 unique 规则；
  非 http(s) 链接禁用该项）；
- **Copy Link Text**：右键时经 elementInfo/JS 取锚文字 → 复制
  （取不到时禁用该项，不弹空剪贴板）；
- 容器/无痕右键项已存在，保持不动。

### ② Agent 基础：成本感知路由 2.0

- 现状：`RoutingDecision` 按**能力**决策（端上/云、工具链锁云、旁路轻调用
  走指定档案）；价格表已有（`modelPrices`，精确匹配）。
- 本版加：**按成本决策的可选策略**（设置三档：关闭 / 智能——上下文大、带
  工具流量或明确指令走主模型，轻对话走便宜档 / 总走便宜档；仅在用户已填
  单价时可选）；每次路由决策（目标模型 + 触发原因 + 预估节省）记进消息
  元数据，轨迹页与统计页呈现"路由分布与节省"；决策纯逻辑进 harness；
  失败回退主模型（便宜档报错不吞）。

### ③ 融合："发送到…"统一动作

- 历史/下载/书签行统一出现发送组：**存为摘录 / 发到白板 / 交给 Agent 起草 /
  用工具箱处理**（复用 `ResultDispatchBar`/`ToolboxHandoff`/摘录起草既有路径；
  行级动作不新增存储形态）。

### ④ 替人干活：下载链接文件进台账 + 死链值守

- 右键下载即台账作业（暂停/恢复/失败重试天然复用，无需新机制）；
- 书签死链检查接入定时值守：`ScheduledTask.jobTemplate` 已支持后台命令，
  本版补一个**内置流水线 `bookmarkLinkCheck`**（到点跑检查、产出报告、异常
  才通知——复用免打扰分级）。

## 贯穿

- **可靠性**：下载复用台账原子写；书签拖拽的持久化走既有移动 API（不新增
  存储形状）；路由决策纯逻辑进 harness。
- **可发现性**：右键两项、书签栏手势、发送组——全部进 What's New；统计页
  新增路由分布小节。
- **i18n**：新文案三语在提交时补齐（CLI 构建不抽键）。
- **验收口径**见下。

## 不做

- 书签同步的冲突合并策略改动（同步域按既有 LWW，不新增结构）；
- 凭据/密码类新功能；passkey（等 Apple entitlement）；
- VideoPro 关键帧/色轮/混音台（媒体大件另立版本）；
- Remote/iPad 面扩展（0.8.38 遗留清单另立版本）；
- 主回合"自动换模型"的激进形态（只做用户显式开启的三档策略）。
