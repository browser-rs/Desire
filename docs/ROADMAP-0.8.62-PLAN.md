# v0.8.62 规划稿（2026-11-17）—— 读遍世界：翻译 2.0 + 锁屏语义工具化（丰富版）

> **主题叙事**：网页双语对照翻译（v0.7.20 对照式 / v0.8.8 替换式）是高频功能，
> 但代码里躺着三个真实的限制（本稿动笔前逐一核实实锤）：①**只翻前 60 块 /
> 15k 字符**——长文后半段永远不翻；②**走当前主模型**——每页翻译烧主线额度
> （0.8.60 的旁路档案路由已存在却没接上）；③**零缓存**——同页面每次导航重翻，
> 重开标签再花一遍钱。本版把翻译做成完整体验：全页、便宜、记得住、有品控、
> 可存档。规划前核实：对照/替换双模式、右键/桥入口、reapplyIfActive 导航
> 重施均已存在——本版是增强不是重写；代码块（pre/code）天然不在收集选择器
> （BLOCK_SELECTOR 不含 pre ✓），但**段落内 inline code 会被一起机翻**（术语/
> 变量名弄坏——真实痛点，批 3 保护）。

## 四主题

### ① 浏览器基础（旗舰）= 翻译 2.0（六子项）
- **1a 全页翻译（滚动懒翻）**：`maxBlocks/maxChars` 硬上限改为"首屏即翻 +
  滚动懒翻"——collect JS 分两段：首屏块立即入批；滚动到新内容时收集新块
  续批（沿用 runToken 防串）。`maxChars` 从单次硬限改为**单批预算**。
- **1b 旁路档案省钱**：翻译默认走 `preference.bypassPreferences() ?? 当前
  档案`（0.8.60 已有的便宜模型路由；未配旁路 = 现状回落，行为不变）。
  bypassPrefs 是轻量实例，`collectText` 同款管道直接可用。
- **1c 翻译缓存**：`translation-cache.json`（DiskStore key）——键 = URL +
  块序号 + 原文 hash，值 = 译文；`reapplyIfActive` 先查缓存命中即插（零模
  型调用），未命中块才进批。LRU ~50MB（复用 ArchiveGC 手法）。
- **1d 质量与保护**：
  · **inline code 占位保护**：collect 时把块内 `<code>` 子元素替换为占位
    符（`⟦0⟧`），apply 时还原——术语/变量名不再被机翻弄坏；
  · **失败批次重试一次**（网络抖动的单批失败不再让长页翻译半途而废）。
- **1e 站点自动双语**：站点偏好维度"此站点打开即自动双语"（复用站点偏好
  机制，批内核实现挂点）——常读外文站一次设置永久生效。
- **1f 双语导出**：翻译完成后可导出 **Markdown 对照文档**（原文/译文交错）
  → 存下载目录或送入摘录库/书架——"读遍世界"的"读后存档"闭环。

### ② Agent 基础 = 锁屏语义工具化 + 记忆可视化（两小件）
- **锁屏语义（0.8.61 教训产品化）**：值守处置（.handle）在锁屏时**不再静默
  失败**——标记"等解锁"，解锁后自动重发（resumeUsed 闸不变）；
  `GET /diag/health` 增 `screenLocked` 字段；Doctor 同步。
  实现：System Events frontmost 探针的 app 内等价物（批内定——CGSession /
  NSWorkspace 组合候选）。
- **记忆面板使用反馈可视化**：0.8.60 给 MemoryFact 加的 usageCount/
  lastUsedAt/negativeCount 目前只有检索在用、**面板不可见**——记忆行显示
  "用过 N 次 · 最近 xx"徽标 + 提供"最近常用"排序入口。

### ③ 可发现性 = 设置"翻译"独立 Section
- 默认模式（对照/替换）、站点自动双语管理列表、术语表入口（见批 5）、
  缓存体量与清理按钮；TranslateBar 升级：进度、缓存命中数、当前所用档案名
  （费用可见）。

### ④ 工程
- 两套件的激活探针抽共享 helper（0.8.60 遗留重复代码）；翻译缓存 LRU 与
  ArchiveGC 手法一致；i18n 三语；AGENTS 增补翻译管道纪律；WhatsNew。

## 批 5 候选（可选，默认不做）

- **术语表**：用户自定义术语对照（人名/产品名固定译法），翻译时注入提示词
  ——术语一致性价值高、实现直白（prompt 注入对照表 + 设置页管理），但
  提示注入面需要把关（术语内容来自用户自己，风险低）。
- **TTS 朗读译文**：readAloud 已有英文朗读；译文朗读的语音选择/断句联动
  需要评估，反馈驱动。

## 不做

## 风险

- 懒翻的滚动触发与 SPA/无限流式页面的交互——**保守白名单式**：只在"块数
  超过 60"时才启用懒翻，普通页面行为不变（零回归风险）。
- 缓存键含原文 hash：页面动态内容（时间戳/随机数）会造成命中率低——按块
  粒度缓存（单块 hash 天然抗页面级噪音），而非整页。
- bypassPrefs 未配置时回落主模型（现状），TranslateBar 显示当前所用档案名
  ——费用可见。
- inline code 占位符替换/还原在复杂嵌套（code 内套链接）下的边界——占位
  符选择避开正文可能出现的形式 + apply 侧找不到占位符时保留原文兜底。
