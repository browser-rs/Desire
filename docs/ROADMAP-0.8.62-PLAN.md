# v0.8.62 规划稿（2026-11-17）—— 读遍世界：翻译 2.0 + 锁屏语义工具化

> **主题叙事**：网页双语对照翻译（v0.7.20 对照式 / v0.8.8 替换式）是高频功能，
> 但代码里躺着三个真实的限制（本稿动笔前逐一核实实锤）：①**只翻前 60 块 /
> 15k 字符**——长文后半段永远不翻；②**走当前主模型**——每页翻译烧主线额度
> （0.8.60 的旁路档案路由已存在却没接上）；③**零缓存**——同页面每次导航重翻，
> 重开标签再花一遍钱。本版把翻译做成完整体验：全页、便宜、记得住。规划前
> 核实：对照/替换双模式、右键/桥入口、reapplyIfActive 导航重施均已存在——
> 本版是增强不是重写。

## 四主题

### ① 浏览器基础（旗舰）= 翻译 2.0
- **全页翻译（滚动懒翻）**：`maxBlocks/maxChars` 硬上限改为"首屏即翻 +
  IntersectionObserver 懒翻"——collect JS 分两段：首屏块立即入批；滚动到
  新内容时收集新块续批（沿用 runToken 防串）。`maxChars` 从单次硬限改为
  **单批预算**（总量跟随页面）。
- **旁路档案省钱**：翻译默认走 `preference.bypassPreferences() ?? 当前档案`
  （0.8.60 已有的便宜模型路由；未配旁路 = 现状回落，行为不变）。**注意**
  bypassPrefs 返回的是轻量实例，`collectText` 同款管道直接可用。
- **翻译缓存**：`translation-cache.json`（DiskStore key）——键 = URL +
  块序号 + 原文 hash，值 = 译文；`reapplyIfActive` 先查缓存命中即插
  （零模型调用），未命中的块才进批。容量 LRU（复用 ArchiveGC 手法，上限
  ~50MB）。
- **入口增强**：TranslateBar 显示缓存命中数；右键菜单"双语阅读"已有入口
  照旧。
- **测试**：缓存键计算/命中判定/LRU 上限进 harness（纯逻辑）。

### ② Agent 基础（小件）= 锁屏语义工具化（0.8.61 教训产品化）
- `SessionGuard.isFrontmostAvailable()`（System Events frontmost 探针的
  app 内等价物——CGSession + NSWorkspace 组合，批内定实现）：值守处置
  （.handle）在锁屏时**不再静默失败**，标记"等解锁"并在解锁后自动重发
  （resumeUsed 语义不变——重发沿用同一闸）。
- `GET /diag/health` 增 `screenLocked` 字段；Doctor 同步。
- **测试**：状态判定纯逻辑进 harness。

## 风险

- 懒翻的滚动触发与页面 SPA/无限流式页面的交互（白名单式保守：只在"块数
  超过 60"时才启用懒翻，普通页面行为不变——零回归风险）。
- 缓存键含原文 hash：页面动态内容（时间戳/随机数）会造成命中率低——按
  块粒度缓存（单块 hash 天然抗页面级噪音），而非整页。
- bypassPrefs 未配置时回落主模型（现状），在 TranslateBar 上显示当前所用
  档案名——费用可见。
