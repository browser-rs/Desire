# v0.8.74 规划稿（2026-11-22）—— 执行底座：成本与速度的真值（Agent 基础旗舰）

> **背景**：智能体主线三连（0.8.71 上下文读侧 / 0.8.72 记忆技能写侧 /
> 0.8.73 学习闭环）之后，本版回到**基础能力**——执行底座的成本、速度与
> 韧性。导火索是一次量化：**真实请求 p50 = 130,788 prompt tokens**
> （86 个采样，min 94k / max 183k）。其中相当比例是**每次请求都重复发送的
> 固定基础**（106 个工具的 schema ≈10 万字符量级 + 分层提示词）。0.8.71
> 交付了 prompt_tokens 真值，但"这 13 万 token 由什么构成"仍然不可见。
>
> **原则**：先量化（分层计量），再优化（schema 瘦身，用真值验收），再补
> 观测（TTFT 进轨迹）。不赌架构（工具动态子集否决——能力风险），只做
> 可度量、可回退的基础工程。

## 规划前核实（2026-11-22，防误立）

- **真实成本已可测**：0.8.71 的 usage 真值落在消息上（promptTokens），本机
  86 个采样 p50=130,788——但**无分层拆解**（不知道 system/tools/历史各占多少）。
- **工具 schema 是固定大头**：Definitions 文件 description 总量 ≈10 万字符
  （含参数描述），最长单条 2,356 字符（ImagePro 驱动说明）。每请求全量发送；
  工具索引行（promptInventory）取首句 ≤150 字符 ✓ 已是短版。
- **TTFT 无观测**：模型调用的首 token 延迟、总耗时没有任何记录（grep 零命中）；
  工具耗时已有（toolDurationMs ✓）——模型侧是盲区。
- **超时是二元制**：120s 默认 + noTimeoutTools 豁免集，无按工具分级。
- **已有不复做**：readonly 并行批、工具结果 8k 摘要+转存、空响应/溢出重试、
  failover、editFile（已是锚定替换 find/replace/all）、检查点工具级续跑、
  usage 真值（0.8.71）、学习/记忆/技能全家（0.8.72/73）。

## 旗舰 A：分层计量（先量化）

- **请求分层账本**：构建请求时逐层计量字符数（identity / memory / skills /
  tools-index / environment / page_context / history / tools-schema）→
  ① 日志一行（分层构成，debug 可查）② `/context` 增加分层段 ③ 会话级
  累计进统计页。
- prompt_tokens（服务端真值）与分层字符账并排展示——字符账管构成，token
  真值管成本。
- **产出即基线**：批 2 瘦身用同一把尺验收。

## 旗舰 B：工具 schema 瘦身（最大杠杆）

- **审计 106 个工具的 description + 参数描述**：保留语义关键（何时用、
  风险约束、参数单位/口径），砍冗余 prose（背景故事、重复示例、与系统
  提示词重复的安全说明——安全边界留在系统提示词层，不逐工具重复）。
- **目标**：schema 字符 −30~40%（真值验收：瘦身后真实请求 prompt_tokens
  对比，同会话同问题前后对照）。
- **纪律**：① 纯文案改动（零逻辑）；② 每个工具描述保留首句（promptInventory
  索引行的来源）；③ 分文件过目，不一次性盲改；④ 长描述 Top10 优先
  （ImagePro/VideoPro/批量下载五条 ≈7k 字符）。
- **能力回归**：190 全量 + 工具密集用例（抓取/下载/编辑器）手工探针。

## 旗舰 C：模型调用性能真值（TTFT / 总耗时）

- 每次模型调用记录：**TTFT（首 token 到达）+ 请求总时长**，挂到消息上
  （toolDurationMs 同款模式：派生不出来就落盘）。
- 轨迹页/统计页展示：按模型的 TTFT p50 / 总时长——网关慢不慢、换模型快不
  快，第一次有真值可查。
- 管道基础已在：usage chunk 捕获处加时间戳即可（流式事件首到达时刻）。

## 小件（执行韧性 polish）

## 不做

工具动态子集（能力风险——模型只能调 tools 参数里声明的工具，裁剪即阉割；
描述瘦身已覆盖成本大头）；prompt cache 显式标记（网关自动处理）；多模型
并行请求比价；评估集自动入 CI；Android / iOS Watch；向量重推；AGUI 协议；
浏览器内代理/节流/第三方翻译（既有否决维持）。

## 风险

- **瘦身丢语义**（模型误用工具）：纪律四条（保留首句/约束/单位，砍背景与
  重复）+ 真值前后对照 + 190 + 工具密集探针；改动纯文案可逐条回退。
- **分层计量口径漂移**：与请求组装同源（assembleRequestMessages 内计量，
  不另算一套）。
- **TTFT 口径**：流式首事件时刻 − 请求发出时刻；usage chunk 先到不影响
  （取首个任意事件）。
- **网关计费差异**：真值是服务端自报，跨网关可比性有限——统计页按模型
  分组展示，不做跨网关排名。
