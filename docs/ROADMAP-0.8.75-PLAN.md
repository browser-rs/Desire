# v0.8.75 规划稿（2026-11-23）—— 智能体驾驶舱：把 71-74 的机器装上仪表（Agent 基础旗舰）

> **背景**：智能体四连（0.8.71 上下文 / 0.8.72 记忆技能 / 0.8.73 学习闭环 /
> 0.8.74 执行底座）交付了大量**机器**——分层计量、TTFT 真值、教训记忆、
> 记忆体检、技能闭环——但它们的**可见性与可达性**还是毛坯：

## 旗舰 B：教训效果读数 + Doctor 增项

- **教训效果追踪**（聚合口径，不做逐条归因）：回合收尾时——本回合注入过
  correction 事实 且 回合失败 → lessonRepeatAfterInject +1；注入且成功 →
  lessonAppliedOk +1。两个计数器进：`/memory-checkup` 报告尾行 + Doctor
  检查项 + 会话外备注。**不自动弱化**（回合失败 ≠ 教训失败，归因太粗——
  点踩仍是教训负反馈的唯一自动通道）。
- **Doctor 增项**（复用既有 Check 模式）：
  ① schema 体积漂移（lastRequestLayers.toolsSchema vs 0.8.74 基线 17.8 万，
  ±20% 告警——MCP 工具膨胀的哨兵）；
  ② 体检新鲜度（上次 checkup 距今天数 >30 提示）；
  ③ 教训账本（今日已提取/上限，节流打满提示）；
  ④ TTFT 异常（modelPerf 样本 p50 > 8s 提示网关慢）。

Android / iOS Watch；向量重推；AGUI；crew 重写（既有否决全维持）。

## 风险

- **隐私面扩大**（/prompt 输出记忆与页面预览）：SecretRedactor 全量过一遍 +
  只进会话面板（不进落盘备注、不进同步域）。
- **chip 点击的意外弹层**：popover 而非 sheet，Esc/点击外部关闭；窄面板
  不遮挡输入框（宽高上限）。
- **Doctor 假警报**（新检查项阈值）：schema 漂移 ±20%、TTFT 8s 等阈值先
  放宽起步，宁缺毋滥；"观测窗口未热"沿用协作池检查的先例（样本不足不判失败）。
- **教训读数误读**（把回合失败全归给教训）：报告行明示"聚合口径，非归因"。
