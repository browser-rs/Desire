## Track A — 常规四主题（19 件）

### ① 浏览器基础（旗舰：把"暂缓"的日常能力做实）

**1. 整词查找（spike 先行，不做假开关）**
- **现状依据**：`WKFindConfiguration` 无整词选项（S13）；现有查找走 WebKit `find` +
  `findCountJS`/`findSnippetJS` 自绘计数与上下文（`ContentView.swift:1121-1175`）。
- **增量**：先做 1–2 天 spike：CSS Custom Highlight API + TreeWalker 做整词命中，
  自绘高亮/上一个/下一个/计数；只对文本节点、跳过 `script/style/code/pre` 与
  Shadow DOM 深处；不可用的页面（canvas/iframe 跨源）明确显示"此页不支持"，
  **不做只对一半页面生效的开关**。若 spike 结论是不可靠，文档写明并撤项。
- **验收**：spike 结论进 AGENTS；fixture 页（中英文/标点/大小写/Shadow DOM）E2E：
  命中数、当前项、跳转、清除高亮；失败页面有明确提示。

**2. 历史保留策略**
- **现状依据**：`HistoryStore` 只有 `clearAll` / `removeAll(after:)`（S14），没有自动保留。
- **增量**：设置"历史保留 N 天"（默认 0 = 永久；7/30/90/365）；启动 + 每日 GC；
  与存储页/隐私中心同源；清理只删历史，不碰书签/阅读列表；当前会话不受影响。
- **验收**：harness（保留判定）+ 桥 E2E（写入旧/新记录 → 设置 30 天 → 只删旧的）；
  存储页显示历史体量与保留期。

**3. 支付卡自动填充（加密卡库，CVV 不落盘）**
- **现状依据**：`FormAutofillProfile` 只有地址字段（S15）；无卡模型/卡库/卡填充脚本。
- **增量**：`PaymentCardProfile`（持卡人/卡号/过期/账单邮编，**不存 CVV**）；Keychain
  加密存储（复用 `KeychainService` 的条目模型，独立 account）；卡库增删改；站点弹层
  按卡填充（只填空字段；卡号分段输入兼容）；首次使用明确提示"CVV 每次手输"。
- **验收**：harness（卡号格式/过期校验/脱敏）+ 本地 fixture 表单 E2E（填充/不覆盖/
  CVV 不落盘）+ Keychain 隔离断言（封闭实例 secrets=file）。

**4. 密码健康动作闭环**
- **现状依据**：健康卡能列出弱/重复/旧（0.8.80）；导出是明文 CSV（S16），
  没有"去改密"动作。
- **增量**：健康行加"去改密"（打开站点登录页 + 自动填充当前账号）；"标记已处理"
  （不删凭据，只从健康卡隐藏 30 天）；**加密导出**（密码口令 + AES-GCM，文件带
  版本头；明文 CSV 保留但明确风险）；重复密码一键跳到另一条。
- **验收**：harness（加密导出 round-trip/错口令拒绝）+ 桥 E2E（健康动作状态）+
  快照；不碰真实钥匙串（封闭实例 file keychain）。

**5. 标签组 → 工作区/模板**
- **现状依据**：标签组支持重色/折叠/拖入（0.8.80）；`TabGroupStore` 有
  `suspendGroup`/`setCollapsed`，但组不能直接存成工作区或作为"打开一组"的模板。
- **增量**：右键组 →"存为工作区"（复用 WorkspaceStore，名字默认组名）；"从组打开
  新窗口"（组内 URL 一次开齐）；组内全部挂起/恢复；组搜索/过滤（⌘⇧A 里按组）。
- **验收**：桥 E2E（组→工作区往返、组内挂起/恢复）+ 快照；用户手测组操作手感。

### ② Agent 基础（旗舰：新能力的边界与可见性）

**6. 定时任务错过补偿**
- **现状依据（已修正）**：每日/间隔任务**本来就有**启动补跑（`lastFiredAt` 旧值 +
  当天到点判定），S9 原文"只记 missed、没有 catch-up"不成立；真实缺口是**每周**
  任务——旧判定要求今天正好是设定星期，整周关机后错过的一次永远不补。
- **已落地（v0.8.81 批 3）**：判定抽成 `ScheduleDue`（Foundation-only）；每日/每周
  超过 5 分钟宽限标为补跑，每周按"最近一次应跑时刻"判定（下一次 ≤2 小时则让正常
  时刻跑）；`RunRecord.catchUp/scheduledFor` + 任务行"已补跑"；设置页开关
  `agent.catchUpMissedRuns`；锁屏/免打扰沿用既有守卫。
- **验收**：harness 5 组（间隔/每日/每周/开关/今天已跑）+ 桥 E2E（回填
  `lastFiredAt` → 下一个 tick 补一次、下一 tick 不重复）已过。

**7. 提示词缓存前缀稳定**
- **现状依据**：`<tools>` 段按当前可用工具生成，scoped tools 在回合中会变（S10）；
  缓存命中已计量，但没有"前缀稳定性"审计。
- **增量**：① 把工具索引拆成"稳定前缀（全量目录/分组）+ 动态尾部（本轮加载的
  scoped tools）"，让 system + 全量工具索引尽量不随回合抖动；② 请求前记录
  "前缀哈希"（前 N 字符），命中/未命中与变更原因（工具集变化/记忆更新/会话指令）
  进 trace；③ 在统计页给"缓存友好度"提示（如"本轮工具集变化，缓存可能失效"）。
- **验收**：harness（前缀哈希/稳定性判定）+ 假端点 E2E（同一会话两回合 system
  前缀一致；scoped tools 变化时 trace 标注原因）+ 统计页快照。

**8. 审批批处理安全升级**
- **现状依据**：批量匹配只看工具 + 站点 + 顶层参数键（S11），没有预览/上限；
  危险工具已排除，但"将放行几条"不可见。
- **增量**：审批卡上"批准本轮剩余"前显示**预计放行数/参数形状**（从当前 assistant
  tool_calls 预估）；单次批量上限（默认 8，超过要求逐条）；批量放行写更详细审计
  （工具/站点/参数键/条数）；"本轮"结束即失效（已有）；危险工具永不进批（已有）。
- **验收**：harness（匹配/上限/危险排除）+ 桥 E2E（预览数准确、超上限拒绝、
  审计行字段齐）+ 快照。

**9. 自评修订可见性**
- **现状依据**：修订只标 `wasRevised`（S12），没有前后对照/理由。
- **增量**：修订时保存 `originalAnswer`（会话内，不回传模型）；消息卡显示
  "已按自评修订"折叠块，支持"查看修改前/后"（diff 视图）；修订理由来自 critique
  （摘要一行）；提供"撤销修订"（恢复原文，记一次审计）；高风险/工具失败回合默认
  仍只提示不自动改（保持 0.8.80 门槛）。
- **验收**：harness（diff 生成/恢复）+ 假端点 E2E（critique → 修订 → 卡片显示
  前后 → 撤销恢复）+ 快照。

**10. 上下文预算与转存工作台**
- **现状依据**：预算控件只在设置页（`AgentSettingsSection.contextBudgetSection`）；
  转存结果只有徽标（`AgentToolCallList.SpellResultBadge`），没有搜索/查看器；
  Remote 看不到预算。
- **增量**：① 模型菜单/状态行显示当前档案的预算与触发阈值（点击直达设置）；
  ② 转存结果"查看"打开只读查看器（搜索 grep、按 offset 切片、Finder 显示）；
  ③ Remote 快照带预算/占用（已有 context%，补 budget/trigger）。
- **验收**：桥 E2E（预算读写已具备；查看器搜索/切片）+ 快照（宽/窄）+ iOS 帧契约。

**11. Agent 评估与回归门禁**
- **现状依据**：0.8.80 新增了缓存/批处理/修订/预算，但评估集没有覆盖这些契约；
  `agent-eval.py` 仍是旧用例集。
- **增量**：新增 E34–E38：缓存命中/前缀稳定、批量审批预览与上限、修订 diff/撤销、
  预算/转存、错过任务补偿；全部假端点确定性；CI 只跑纯逻辑/桥契约，不跑真模型。
- **验收**：`agent-eval.py --only E34,E35,E36,E37,E38` 全过；harness 计数更新；
  失败样例进回归清单。

### ③ 融合（浏览器 + Agent / 跨端）

**12. iOS 账号安全 UI（只读部分已落地；改密不做）**
- **现状依据**：服务端已有改密/恢复码/审计/设备吊销（0.8.80），iOS 设置页只有登出

- **增量**：设置页新增"账号安全"：改密（当前/新/确认）、恢复码生成/复制（只显示
  一次）、审计最近 50 条、设备列表/吊销；能力门控（旧服务端无端点时隐藏并提示

- **验收**：iOS 帧/API 契约测试（假服务端）+ 模拟器构建 + 真机联调；服务端
  E2E 覆盖"改密 → 旧 access 401 → 当前设备 refresh 成功"。
- **实施记录（v0.8.81 批 6）**：已接恢复码生成/复制、最近 50 条审计、设备列表与

  的同步数据永久不可解。要做必须先在 iOS 实现密钥托管/重包链路。

**13. Remote 批次启动 / 窗口 / 追加（批 4 已落地）**
- **现状依据**：Remote 只能控制已有批次（S6）；不能从手机提交 URL 列表、设窗口、
  开始新批次。
- **增量**：手机端"新建批量下载"（URL 列表/站点当前页解析结果预览）、设文件夹/

- **增量**：冲突列表每条提供"采用本地 / 采用远端 / 以后再说"（仅对可逆域：
  书签/快拨/阅读列表/设置；历史/记忆不提供破坏性覆盖）；"重试同步"/"清冲突记录"

**15. Remote 投递确认（ack）与离线可见（批 4 已落地）**

**16. Remote 标签页/标签组操作补全（批 4 已落地）**

### ④ 替人干活（3 件）

**17. 任务链运维（批 6 已落地：路径/重试/继续）**
- **现状依据**：任务卡显示 `chainTo`，但没有"整条链预览/从某步继续/失败重试策略"；

  步骤）；每步失败重试策略（0/1/2 次、退避）；链执行记录按 run 可追溯。
- **验收**：harness（链解析/环检测）+ 桥 E2E（两步链失败 → 从第二步继续）+
  快照。

**18. 作业模板输出交接（批 5 已落地：模板参数）**
- **现状依据**：任务链支持 `{{prev.*}}`，但 `jobTemplate` 的参数是静态的
  （`AgentScheduler.ScheduledTask.jobTemplate`）；作业模板之间不能传上一轮产物。
- **增量**：jobTemplate 参数支持同一套占位符（`{{prev.output}}`/`{{prev.artifacts}}`）；
  链上"命令模板 → 报告任务"可引用产物路径；执行记录标注渲染后的参数（脱敏）。
- **验收**：harness（模板渲染/占位符校验）+ 桥 E2E（模板链两步，第二步拿到产物）。
- **实施记录（批 5）**：模板**参数**已支持占位符并从链上下文渲染；运行记录保存
  脱敏后的实际命令行。**未做**“命令模板完成后把作业输出交给下一任务”——
  `BackgroundCommandStore` 的作业完成目前不回流到调度器，需要新增 job→scheduler
  回调（留待下一版，不在文档里假装已通）。

**19. 普通下载调度（批 5 已落地：窗口/排队；限速不做）**
- **现状依据**：批量下载有时段窗口/并发（0.8.80）；普通 URLSession 下载没有
  队列优先级/时段/全局限速。
- **增量**：下载设置增加"同时下载数"（1–5）、"时段窗口"（可选）、"限速"
  （NSURLSession 无公开 per-task 带宽，先做并发/时段；限速若不可靠不做假开关）；
  队列行显示等待原因；与批量窗口同一套判定。
- **验收**：harness（窗口/并发判定）+ 桥 E2E（并发上限/时段暂停）+ 设置快照；
  限速先 spike，结论写明。

## 风险

- **WebKit 查找**：整词无公开 API，自绘高亮可能破坏 React/Shadow DOM；spike
  结论决定做不做，不做假开关。
- **支付卡**：Keychain 条目模型与加密格式要一次定对；CVV 绝不落盘。
- **token 版本迁移**：0021 必须先跑；旧 token 无版本字段按 0 处理，升级窗口内
  仍有效到过期，部署说明写清。
- **缓存前缀**：工具索引拆分可能影响模型工具选择；A/B 用假端点 + 真模型小样本
  对比，命中率与任务成功率一起看。
- **锁屏/错过补偿**：补跑不能与用户刚发起的回合抢同一会话；串行队列 + 可见
  "补跑"标记。
- **测试**：fresh data-dir 会增加磁盘占用；每次跑完清理，报告保留摘要。
