## Track A — 常规四主题（17 件）

### ① 浏览器基础（旗舰：密码与支付安全）

**1. 加密密码导出/导入**
- **现状依据**：`exportCSV()` 把域名/用户名/密码明文写文件（S3）。
- **增量**：新增密码保护的加密导出（口令 + 随机盐 + AES-GCM，CryptoKit）；
  明文 CSV 保留但标“不安全，仅临时迁移”；导入支持加密包与 CSV，按域名+用户名
  合并、不覆盖更新时间更新的条目；临时文件用完即删。
- **验收**：harness（round-trip / 错口令拒绝 / 合并规则）+ 桥 E2E（导出→导入→
  条目数与秘密一致）+ 快照；不碰真实钥匙串（封闭实例 file keychain）。

**2. 密码健康“已处理 / 稍后提醒”**
- **现状依据**：`PasswordHealth.findings` 每次全量重算，没有处理状态。
- **增量**：每条发现可标“已处理”（隐藏）或“30/90 天后提醒”；本地持久化、
  可撤销；健康卡显示“已处理 N 条”；不改变密码本体。
- **验收**：harness（状态机/到期恢复）+ 桥 E2E（标记后健康卡计数变化）+ 快照。

**3. 支付卡自动填充（设计评审通过后实施）**
- **现状依据**：`FormAutofillProfile` 只有地址字段；没有卡模型（S4）。
- **增量**：独立 Keychain 卡保险库（卡号/有效期/持卡人；**CVV 永不落盘**）；
  结账表单字段识别与填充；填充前显式确认；仅本机、暂不进同步；卡品牌/末四位展示。
- **验收**：设计评审（威胁模型/Keychain ACL/CVV 不落盘）+ fixture 表单 E2E
  （填充值/已有值不覆盖/确认前不填）+ 快照；评审不过则顺延，不做半成品。

**4. 标签概览按组过滤/搜索 + 整组挂起**
- **现状依据**：`TabOverviewView` 只有网格；`suspendGroup` 只在组面板（S5）。
- **增量**：概览顶部按组胶囊过滤 + 标题/网址搜索；组菜单“整组挂起/恢复/关闭”；
  与标签搜索同一套查询；桥补 `/tabs/overview` 过滤参数。
- **验收**：桥 E2E（过滤/搜索/整组挂起/恢复）+ 快照；不改变现有标签搜索快捷键。

**5. 纯文本缩放 spike（不做假开关）**
- **现状依据**：页面缩放已有；纯文本缩放没有公开 API，CSS 注入会与站点样式打架。
- **增量**：1–2 天 spike：仅对正文文本节点注入相对字号，验证 React/Shadow DOM/
  阅读模式；不可靠则文档写明并撤项。
- **验收**：spike 结论进 AGENTS；不做只对一半页面生效的设置。

### ② Agent 基础（旗舰：任务链可观测与恢复）

**6. 任务日历与下次运行**
- **现状依据**：任务卡只有周期文本与最近运行（S6）。
- **增量**：统一日历视图（日/周/区间）：每日/每周/间隔任务的**下一次与后 10 次**、
  已错过/已暂停/补跑标记；跨午夜窗口与夏令时按本地时区计算；桥
  `GET /agent/tasks/calendar?from=&to=`。
- **验收**：harness（下次运行/跨午夜/DST）+ 桥 E2E（创建任务→日历命中）+ 快照。

**7. 运行历史与产物视图**
- **现状依据**：`RunRecord` 已有 prompt/output/scheduledFor，但 UI 只有条形图。
- **增量**：任务详情抽屉：最近 20 次运行（状态/耗时/输出/产物/重试次数）、
  按状态过滤、失败原因复制；输出复用转存查看器（大文本搜索/切片）。
- **验收**：桥 E2E（运行记录字段齐全）+ 快照（宽/窄）。

**8. 链级失败恢复**
- **现状依据**：`continueChain` 只能从上游成功输出继续；没有“整链状态”（S7）。
- **增量**：链状态（waiting/running/success/failed）与每步最近运行；失败步提供
  “从这步继续”和“重跑整链”；链上后续步骤不再静默跳过，失败通知带动作。
- **验收**：harness（链状态归并）+ 桥 E2E（两步链第二步失败→从第二步继续→
  整链完成）+ 快照。

**9. 评估集 E34–E38**
- **现状依据**：0.8.81 新契约没有评估用例（S12）。
- **增量**：假端点确定性用例：缓存前缀稳定、审批预览/上限、修订 diff/撤销、
  预算/转存、错过补跑；`agent-eval.py --only E34,E35,E36,E37,E38`。
- **验收**：全过；CI 只跑纯逻辑/桥契约，不跑真模型。

**10. 预算测试时序修复 + 正式探针**
- **现状依据**：MUSCLE17 立即读预算，usage 落账晚于断言（S8）。
- **增量**：套件改为轮询预算状态（最多 5s）；新增 `tests/budget-probe.py`
  （单窗口、假端点、460→warning、920/stopLevel=2/无 B-DONE）；190 不再把
  预算 5 项当已知 flake。
- **验收**：连续两次 190（fresh 目录）预算 5 项全过；探针可单独运行。

### ③ 融合（旗舰：跨设备一致闭环）

**11. 同步冲突明细与“采用本地/远端”**
- **现状依据**：冲突只有 domain/label/at，没有条目身份与两版载荷（S1）。
- **增量**：冲突台账记录 `domain/clientId/localID/服务端胜者密文/本地快照`；
  仅对可逆域（书签/快拨/阅读列表/设置）提供“采用本地/采用远端/以后再说”；
  “采用本地”= 提升本地 updatedAt 后重推；“采用远端”= 确认服务端版本；
  二次确认 + 审计；历史/记忆不提供破坏性覆盖。
- **验收**：harness（冲突归并/域白名单）+ mock 同步端点 E2E（造冲突→选择→
  两端一致）+ 快照；不做假按钮。

**12. iOS 改密可行性 spike（决策门）**
- **现状依据**：服务端改密必须重包 DEK；iOS 没有同步主密钥（S2）。
- **增量**：评估 iOS 端密钥托管/恢复链路（Keychain + 服务端 escrow）；
  若不能安全重包，**明确改密仅 Mac**，iOS 只保留恢复码/审计/设备吊销。
- **验收**：spike 结论进 AGENTS；无论做不做，都不在 UI 里提供会破坏同步的改密。

**13. Remote 冲突处理与设备信任**
- **现状依据**：手机同步健康页只有“重试/清记录”，没有逐条冲突动作。
- **增量**：手机展示冲突明细（标签/时间/域），对可逆域提供采用本地/远端；
  设备列表显示信任状态与吊销确认；动作走控制帧，Mac 执行。
- **验收**：帧契约 + 假服务端 E2E + iOS 构建。

**14. 同步健康审计**
- **现状依据**：冲突解决没有历史；Doctor 只看域状态。
- **增量**：冲突解决记录（谁/何时/选了哪边/结果）；Doctor 增加“未解决冲突”
  与“冲突解决失败”检查；`/sync/health` 带计数。
- **验收**：桥 E2E + Doctor 快照。

### ④ 替人干活（旗舰：值守日历与失败动作）

**15. 统一值守日历**
- **现状依据**：定时任务、批量下载窗口、普通下载窗口分散在三处。
- **增量**：一个时间线合并“任务下次运行/批量窗口/下载窗口/作业链”；显示
  冲突（同一时段过多）、错过、暂停；点击跳对应面板。
- **验收**：harness（时间线归并/冲突检测）+ 快照。

**16. 失败通知动作**
- **现状依据**：失败通知只有文本；用户要回面板找任务。
- **增量**：macOS 通知动作“继续/重试/忽略”（仅定时任务与链）；动作经桥/
  CommandBus 回到调度器；通知里带任务名与失败原因一行。
- **验收**：桥 E2E（触发失败→通知动作→重试/继续）+ 手测通知样式。

**17. 任务失败诊断卡**
- **现状依据**：`TaskFailureClassify` 已能分类错误，但任务卡只显示一行 lastResult；
  用户不知道该改命令、改授权还是等窗口。
- **增量**：失败任务显示原因类别（命令缺失/授权/超时/浏览器不可用/预算/依赖失败）
  + 一句修复建议 + 动作（打开设置、重试、从这步继续、忽略）；与链恢复共用状态。
- **验收**：桥 E2E（四类失败→诊断文案/动作）+ 快照。

## 风险

- **支付卡**：Keychain 条目模型与 CVV 不落盘要一次定对；设计评审不过则顺延。
- **同步冲突“采用本地”**：可能覆盖其它设备的新数据——只对可逆域、二次确认、
  保留服务端胜者快照与审计；不做历史/记忆的破坏性覆盖。
- **iOS 改密**：没有密钥重包链路就绝不提供入口；spike 结论必须写进 AGENTS。
- **预算/启动测试修复**：不能把真实回归一起“修绿”——探针与 190 并行保留。
- **部署验证**：本机没有 MySQL/Docker 时只能 cargo test / skip，不能宣称 DB E2E 已过。
