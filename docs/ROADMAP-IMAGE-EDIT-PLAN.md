# 图片编辑专业化路线（v0.8.41 → 0.8.43，三个迭代）

> 进度：迭代 1 全部完成；迭代 2 图层/修复刷/套索/魔棒/LUT 完成（EXIF/水印/透视留后续）；迭代 3 AI/批量完成。

> 目标（2026-11-04 用户提出）：把现有「预览量级」的图片编辑器（v0.8.12 起，
> 旋转/翻转/裁剪/缩放/标注/10 滤镜/6 调节滑杆/OCR）用三个迭代做成
> **专业级图片编辑**——非破坏管线、专业影调色彩、选区、图层与修复、AI 抠图与
> 批量自动化。仍然零第三方依赖，只用 CoreImage/CoreGraphics/Vision。

## 一、现状核实（不重复造轮子）

已有（`ImageEditorView.swift` 1116 行 + `ImageTransforms.swift`）：

- 几何：旋转 90°、水平/垂直翻转、矩形裁剪（自由/比例）、按宽度缩放。
- 标注：画笔/箭头/直线/矩形/椭圆/多边形/文字/序号气泡/马赛克，落图即烙（flatten）。
- 调节：亮度/对比度/饱和度/锐化/曝光/色温（CoreImage，实时渲染）。
- 滤镜：Vivid/Mono/Chrome/Fade/Instant/Noir/Process/Tonal/Transfer。
- 工程：`.bak` 快照 + 原子写、⌘S、撤销栈（仅回退、无重做/跳转）、历史面板、
  缩放（fit/100%/pinch）、OCR。

缺口：无重做/无参数化重编辑、无直方图、无曲线/色阶/HSL/白平衡/锐化降噪/
晕影/分离色调、无选区、无任意角度拉直/透视、无参考线、无图层、无修复/克隆、
无批量导出/格式面板、无 LUT、无 AI 抠图；编辑器是 1116 行大视图，扩不动。

## 三、迭代 1（v0.8.41）：管线化 + 专业影调色彩

### A1. 非破坏管线核心（地基，决定后面一切）

- `ImageEditPipelineCore`（Foundation-only，进 harness）：操作数组
  `[ImageEditOperation]`——geometry（crop/rotate/flip/resize/straighten）、
  adjustments、selection、annotations、filter preset；每 op 可独立
  `isEnabled`、可改参、可重排；渲染 = 有序应用，带结果位图缓存（尺寸/指纹）。
- `ImageEditorDocument`（@MainActor ObservableObject）：从 1116 行视图里抽出
  状态——文档（URL/位图/管线/历史）、undo/redo 双栈、历史跳转、保存（.bak +
  原子写语义不变）、脏标记。视图只读 document + 发命令。
- 迁移策略：旧编辑动作全部映射为 pipeline op（标注先保持烙图语义，图层化放迭代 2），
  不改变入口（右键「编辑图片」、文件查看器、工具箱）。

### A2. 影调与色彩专业化

- 新增调节：白平衡（temp/tint）、色阶（黑/白/中点）、曲线（RGB + R/G/B，锚点编辑）、
  HSL（8 通道 hue/sat/lum）、自然饱和度、清晰度（structure）、锐化（radius/amount）、
  降噪（luminance/chroma）、晕影（量/羽化）、分离色调（高光/阴影色相饱和度）。
- 直方图：亮度 + RGB 三通道实时小图；裁剪/调节时常驻可选。
- Before/After：按住对比（分屏/长按原样），调节面板内单项重置、全部重置。
- 自定义预设：把当前调节参数存为命名预设（UserDefaults），与内置滤镜并列；
  预设可删除/重命名；复制/粘贴调节（跨文档）。

### A3. 选区基元（约束编辑的最小闭环）

- 矩形/椭圆选区 + 羽化半径；调整/滤镜/标注先限制在选区内；反选；取消选区。
- 虚线蚂蚁线渲染（CoreAnimation 层）；选区不参与导出，只影响编辑作用域。

### A4. 几何与导出

- 任意角度拉直（±45°，边缘自动扩展/裁切二选一）、数字裁剪（精确像素与比例锁定：
  1:1、4:3、3:2、16:9、9:16、原生）、裁剪参考线（三分/黄金/中心/网格，可关）。
- 导出面板：JPEG/PNG/HEIC/（WebP 若 ImageIO 支持）+ 质量滑杆 + 缩放预设
  （100%/50%/长边 px）+ 复制到剪贴板 + 另存为；保留/剥离 EXIF 开关（迭代 2 补编辑）。

### 常规四主题（轻量，不喧宾夺主）

- ① 浏览器基础：大图（≥30MP）打开/编辑性能预算与内存护栏（降采样编辑 + 导出原图
  可选"按原图尺寸重渲"）。
- ② Agent 基础：桥 `POST /image/adjust`、`/image/export`（文件 + 参数 JSON），
  E2E 可驱动；为迭代 3 的 Agent 批量工具打底。
- ③ 融合：剪贴板图片 → 新建编辑文档；截图/右键路径回归。
- ④ 替人干活：导出面板 + 预设即"一次调好、多处复用"。

### 验收（迭代 1）

1. 裁剪 → 曲线提亮 → HSL 减饱和 → 加锐，关闭曲线项后画面只少曲线效果，
   重新打开参数还在；⌘Z/⌘⇧Z 正确；历史可跳转。
2. 椭圆选区 + 羽化 20px 内加锐，只影响选区。
3. 拉直 3° 后主体不斜，四角无黑边（裁切模式）；三分线可见可关。
4. 直方图随调节实时变化；Before/After 长按对比。
5. 导出 PNG/HEIC 质量/尺寸与元数据开关符合预期；剪贴板可直接粘贴到微信。
6. 30MP JPEG 打开 <2s（M 系列实机），编辑不卡主线程 >100ms。
7. 桥端点可程序化完成"打开 → 调节 → 导出"。

## 四、迭代 2（v0.8.42）：图层与修复

- 图层模型：背景图层 + 图像图层（粘贴/置入文件）+ 文字图层 + 形状图层；
  混合模式/不透明度/可见性/重排/变换（移动缩放旋转）；图层面板；烙图导出。
  现有标注工具改为"默认画到当前图层"，旧文档打开自动合并成单背景层（零迁移痛）。
- 可编辑标注：文字/形状/箭头在确认前可再选中改字/改色/移动；烙图时机延后。
- 修复工具：克隆图章（⌥取样）、修复刷（邻域纹理混合的简化 inpaint）、
  加深/减淡、模糊/锐化刷；刷子大小/软硬/不透明度。
- 选区升级：套索、魔棒（容差/连续）、选区转图层蒙版（灰度蒙版，可羽化）。
- 几何进阶：透视校正（四角拖拽）、镜头晕影/畸变轻量修正。
- LUT：导入/导出 .cube；作为管线 op。
- 元数据与水印：EXIF 查看/编辑核心字段（标题/作者/版权/ GPS 清除）；
  文字/图片水印（位置/平铺/透明度/旋转），并入导出面板。
- 验收：两图合成（图层不透明度 60% + 混合模式），文字图层改字不重烙全图；
  克隆图章去除电线杆类直线瑕疵；魔棒容差 20 选天空并做曲线；.cube LUT 生效；
  EXIF 清除 GPS 后导出文件不含坐标。

## 五、迭代 3（v0.8.43）：AI 与批量

- AI 抠图/去背景：Vision `VNGenerateForegroundInstanceMaskRequest` 主体蒙版 →
  一键抠图（导出 PNG 透明底/替换纯色/背景模糊）；自动增强（直方图拉伸 + 白平衡）、
  自动色阶。
- 批量流水线：对文件夹应用同一管线/预设 + 缩放 + 水印 + 格式，走 Job 队列
  （复用 v0.8.40 队列/取消/通知），Agent 工具 `batchEditImages`，桥端点；
  失败逐项可见。
- 收尾打磨：键盘全流程（V/M/L/⌥取样/⌘⇧E 导出/⌥拖动复制图层…）、全屏模式、
  缩略图导出对比、性能剖析（大图 tile 渲染）。
- 验收：10 张照片批量套同一预设 + 水印 + 长边 2048 导出，Job 面板可看进度/失败项；
  抠图头发边缘可用；Agent 一句话完成"把这批图转成 1080p JPEG 加水印"。

## 六、不做（三个迭代内明确）

- 不做 Photoshop 级矢量图形系统、通道级蒙版运算、智能对象、扩展插件系统。
- 不做 RAW 解码器级开发（DNG 只保证可打开 + 基础调节，不做 raw 白平衡管线）。
- 不引入第三方依赖（OpenCV/GPUImage 等）。
- 不做移动端/iPad 编辑器（Remote 只看结果）。
- 不承诺"内容感知移动/变形"这类高难 inpaint（修复刷限邻域纹理混合）。

## 七、风险与取舍

| 风险 | 取舍 |
|---|---|
| 1116 行大视图重构回归 | 迭代 1 先抽 `ImageEditorDocument`，视图行为逐块搬迁；入口/UI 不变，靠既有手测路径回归 |
| CoreImage 主线程卡顿 | 渲染异步化 + 结果缓存（指纹/尺寸），直方图降采样计算 |
| 大图内存 | 编辑位图降采样 + 记忆"源尺寸"，导出时可选按原图重渲；>100MP 拒绝并提示 |
| 非破坏迁移 | 旧文档打开 = 单 op 管线（原图 + 已烙标注），不假装可重编辑旧标注 |
| 选区复杂度 | 迭代 1 只做 rect/ellipse + 羽化；套索/魔棒/蒙版放迭代 2 |
| Vision 可用性 | 抠图 feature-gate（macOS 14+ API，本项目 26.5 无虞），失败给可读错误 |
| 四主题挤占 | 每迭代只带 1–2 件轻量常规项，主体给图片编辑 |
