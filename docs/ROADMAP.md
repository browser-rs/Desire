# Desire 路线图（0.1.x → 0.2）

> 基线：v0.1.0（2026-09-18）。本文基于 2026-09 的全量 QA（自动化桥回归 +
> 修复 9 个真 bug）与 AGENTS.md 已知问题清单制定。
> 原则：**0.1.x 只修不加**（不改架构、不进新子系统），**0.2 做主题化功能版本**。

## 现状基线（v0.1.0 已具备）

- 核心浏览：多窗口（每窗独立会话）、会话恢复、标签（分组/固定/休眠/预览/中键）、
  地址栏解析与建议、beforeunload 表单保护、查找、阅读模式
- 下载：暂停/恢复/重启全链路、无痕隔离、实时进度、面板重设计
- 数据：书签、历史（无痕不记录、标题延迟校正）、阅读列表、搜索历史、密码（Keychain）
- 隐私与屏蔽：容器隔离、内容拦截（ABP 规则/订阅列表）、元素屏蔽、视频广告拦截、
  HTTPS 升级、按域缩放/暗色
- 工具：截图（区域+标注）、响应式模式、DevTools（控制台/网络/检查器）、翻译、
  用户脚本、AI Agent（多模型 + MCP）
- 工程：自动化桥（40+ 端点全链路可测）、CI（Release 构建+产物）、tag 发版

## 0.1.x 补丁线（每 1–2 周，小步快跑）

### 0.1.1 — 稳定与补漏

- **BUG-K 退出挂起**：SIGTERM 后偶发卡 exit。加关闭期诊断（退出时枚举存活的
  URLSession 任务、未决 continuation 并打日志），定位后修。
- **savePage 命令补齐**：快捷键映射已有 `savePage` 但无对应命令——实现
  ⌘S 保存页面（webarchive 或 MHTML），补齐映射到命令的最后一环。
- **历史同 URL 归并**：连续重复访问产生重复条目（FF/Chrome 是每 URL 一条+计数）。
  默认合并连续重复，面板显示访问次数；不做全量合并迁移。
- **密码保存提示改造**：`passwordSave` 已非模态化（sheet），但形态升级为
  地址栏下方轻提示条（Safari 风格），带"本次不保存"与"永远不问此站"。
- **CI 冒烟**：产物上传前启动 app（`--automation`），`GET /state` 200 才算通过，
  防止"能编译不能启动"的发布。

### 0.1.2 — 分发质量

- **Developer ID 签名 + 公证**（可选路径）：secrets 配置证书时签名+公证，
  未配置时回退当前 unsigned 流程；Release 说明自动适配。
- **架构声明**：x86_64 编译检查跑一次 CI（或明确宣布 arm64-only 并写进 README）。
- **Release 说明模板**：加入 SHA256 校验命令示例、系统要求（macOS 26+）。

### 0.1.3 — 交互细节

- 下载完成通知节流：多文件完成聚合为一条系统通知 + Dock 图标角标，
  避免 `requestUserAttention` 连环轰炸。
- 标签拖出成独立窗口 / 回拖合并（macOS 浏览器习惯操作）。
- 地址栏粘贴检测：剪贴板为 URL 时建议首行显示"打开剪贴板链接"。
- 错误页文案复核（ErrorPageView 的 TLS/断网/DNS 分类映射抽查）。

## 0.2.0 — 日用浏览器补全（功能版本）

主题：**能当主力用的最后几块板**。

### 1. 书签栏（最大 UX 缺口）
- 工具栏下方常驻书签栏：叶子直接点击导航、文件夹悬停下拉、
  "其他书签"溢出收纳。
- 拖拽排序与拖入整理；数据源与书签面板/星标一致（同一 BookmarkStore）。
- 可在设置中隐藏（默认显示）。

### 2. 历史与站点权限
- 历史搜索框 + 每 URL 访问计数合并视图（与 0.1.1 的归并策略衔接）。
- `SiteSettings` 扩展 per-domain JavaScript 开关（当前只有全局开关）、
  自动播放策略按域覆盖。

### 3. 密码中心
- 密码生成器（长度/符号可调，保存时自动建议）。
- CSV 导入导出（对齐 Chrome/Safari 格式便于迁移）。
- 泄漏检查（HIBP k-匿名 API，可选开关）。

### 4. Passkey
- Apple private-key-credential entitlement 申请流程走完（docs/ 已有记录），
  实现 WebAuthn 平台凭据的创建/认证 UI。

### 5. 网络拦截层
- 引入真正的 request interception（WebKit Network Interception API）：
  - 响应式模式接入**真**网络节流，拆掉假 UI（AGENTS.md 明令勿再做假 UI）；
  - pixelRatio 模拟补齐；
  - 请求级改写规则（阻断/重定向/改头）作为内容拦截的补充。

### 6. 多窗口 Agent 联动
- Agent 会话绑定窗口（`WindowToolSurface` 已有地基）：任务可指定在哪个
  窗口执行；跨窗口编排（"在窗口 A 查，结果贴到窗口 B"）。

### 7. 性能与资源
- 标签休眠增强：内存水位触发（不止时间阈值）；播放音频/下载中/固定标签
  豁免（部分逻辑已有，补齐矩阵）。
- 启动预算：冷启动到首窗可交互 < 400ms（当前未测，先立基线再优化）。

## 明确不做（本阶段）

- **账号同步**（书签/密码云同步）：需要后端与账号体系，延后到 0.3 评估。
- **iOS/iPadOS 移植**。
- **多语言扩展**：当前 en/zh-Hans(+zh-Hant 自动) 够用。

## 版本节奏与质量门

- 0.1.x：每 1–2 周一个 tag；只进修复与小 UX；每个 PR 过 CI（Release 编译 + 产物）。
- 0.2.0：功能逐个落（每个功能独立 PR + 桥端点 + QA 回归），全量回归通过后
  功能冻结 → 打 tag。回归脚本基于自动化桥（`/state`、`/command`、`/downloads/*`、
  `/beforeunload`、`/find`、`/shortcuts` 等 40+ 端点）。
- 实验项（不承诺）：在 CI runner 上跑自动化桥做无头回归（hosted macOS 有 GUI
  会话，可行性待验证）。
