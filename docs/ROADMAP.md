# Desire 路线图（0.1.x → 0.6.x）

> 基线：**v0.6.0**（2026-10-04，构建号 499）。
> 定位：**AI 原生浏览器**——浏览器本体是 Agent 的执行环境。证据即结构：
> `apps/macos/Desire/Features/Agent/` 为最大模块（百余个工具面、多模型双协议、
> MCP 服务端+客户端、审批/记忆/技能/调度/轨迹/成本），60+ 端点自动化桥是对外
> 驱动与 QA 的一等接口；`crates/` 为自托管后端（E2E 加密同步 + Desire Remote 中继）。
> 节奏：0.6.x 延续 1–2 周一个 tag；每个版本含桥端点与回归验收。
> 本文档 2026-10-05 重写：0.1.x–0.3.x 规划归档于文末（全部交付），0.4.x–0.6.0
> 期间未编路线图直接迭代（四条产品线：白板、DPP、悬浮球、同步/远程），本版起恢复
> "先规划后发货"。

## 0.6.x 主线（六条）与持续轨道

1. **Agent 闭环** —— 记忆→执行→**恢复**→**成本**全闭环：跑一半能续、每一分
   token 都记账、便宜活用便宜模型、多窗口不再割裂。
2. **浏览器本体** —— Agent 之外，浏览器自身的日常体验逐项打磨：标签页与导航、
   信息管理、阅读与朗读、隐私可见性、媒体控制。每个条目都要"能日常用"而不是
   demo（可用性取舍按用户口径判）；共三个专版。
3. **跨设备一致** —— 白板进同步域（第九类）；Remote 从"看"走向"及时"（完成通知、
   长会话不哑）；同步可诊断。
4. **页面控制** —— 在 WebKit 允许的范围内把"拦截/改写/节流"做成 Agent 可驱动的
   一等能力（先 spike 后落地，结论诚实写进文档）。
5. **创作工具链** —— 截图（标注/OCR）→ 白板（模板/演示）→ 悬浮球（可定制
   触盘/拖拽投递）→ DPP 管线（提取一键上板）：把"页面 → 素材 → 作品"的独有
   面做深。
6. **生态可发现** —— DPP 审批粒度/检查器/文档站；白板可分享（单文件 viewer）；
   首启引导；系统快捷指令集成。

**持续轨道（每版必过，不占版本主题）**：clean build 零警告（appintentsmetadataprocessor
豁免）、`tests/run.sh` 全过、agent-eval 全过（新增工具面必须进评估集）、远程 smoke 10 步、
发布七阶段闸门、启动 ≤700ms（现基线 632ms）、流式期间主线程 0 卡顿（`pending main
thread dispatch stuck` 计数 = 0）、三语补全（新键 en/zh-Hant 显式）、CHANGELOG 纪律
（条目随对应 fix 一起提交）、新 UI 的 VoiceOver 标签。

## 0.6.4 — 性能优化

**P0**
- **渲染进程崩溃自愈**：WebContent 进程崩溃（Debug+视频页有过 SIGSEGV 前科）
  目前表现为白屏——`webView(WebContentProcessDidTerminate:)` 自动重载 + 状态
  提示条 + 会话内表单不保（如实标注）。验收：注入崩溃 → 2s 内自恢复可见提示。

  验收：开 30 个标签触发压力 → 非豁免标签挂起、点击即恢复。
- **大页面守护**：单标签内存超阈值挂起 + 通知（无公开 per-tab 内存 API——用
  挂起策略驱动的代理指标：DOM 节点数/历史导航深度，诚实口径写进设置页）。
- **启动深化**：启动分段打点常驻化（当前 632ms 基线），设置页"性能自检"报告
  （启动分段/挂起计数/最近崩溃）。
- **性能预算 CI 化**：启动 ≤700ms 与流式主线程卡死计数进入 CI 门禁（探针手法
  已有：`pending main thread dispatch stuck` 计数）。

  自家 Timer——悬浮球轮询、同步防抖等自查）。
- 流式渲染回归集固化（40KB 流式探针进 CI，防退化）。
