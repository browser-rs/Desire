# Desire 路线图（0.1.x → 0.6.x）

> 基线：**v0.6.0**（2026-10-04，构建号 499）。
> 定位：**AI 原生浏览器**——浏览器本体是 Agent 的执行环境。证据即结构：
> `apps/macos/Desire/Features/Agent/` 为最大模块（百余个工具面、多模型双协议、
> MCP 服务端+客户端、审批/记忆/技能/调度/轨迹/成本），60+ 端点自动化桥是对外
> 驱动与 QA 的一等接口；`crates/` 为自托管后端（E2E 加密同步 + Desire Remote 中继）。
> 节奏：0.6.x 延续 1–2 周一个 tag；每个版本含桥端点与回归验收。
> 本文档 2026-10-05 重写：0.1.x–0.3.x 规划归档于文末（全部交付），0.4.x–0.6.0
> 期间未编路线图直接迭代（四条产品线：白板、DPP、悬浮球、同步/远程），本版起恢复
> "先规划后发货"。

## 0.6.x 主线（四条）与持续轨道

1. **Agent 闭环** —— 记忆→执行→**恢复**→**成本**全闭环：跑一半能续、每一分
   token 都记账、便宜活用便宜模型、多窗口不再割裂。
2. **跨设备一致** —— 白板进同步域（第九类）；Remote 从"看"走向"及时"（完成通知、
   长会话不哑）；同步可诊断。
3. **页面控制** —— 在 WebKit 允许的范围内把"拦截/改写/节流"做成 Agent 可驱动的
   一等能力（先 spike 后落地，结论诚实写进文档）。
4. **生态可发现** —— DPP 审批粒度/检查器/文档站；白板可分享（单文件 viewer）；
   首启引导。

**持续轨道（每版必过，不占版本主题）**：clean build 零警告（appintentsmetadataprocessor
豁免）、`tests/run.sh` 全过、agent-eval 全过（新增工具面必须进评估集）、远程 smoke 10 步、
发布七阶段闸门、启动 ≤700ms（现基线 632ms）、流式期间主线程 0 卡顿（`pending main
thread dispatch stuck` 计数 = 0）、三语补全（新键 en/zh-Hant 显式）、CHANGELOG 纪律
（条目随对应 fix 一起提交）、新 UI 的 VoiceOver 标签。

- 白板增量渲染回归：追加/单块编辑时既有节点不重渲（E2E 断言渲染统计 `rendered`
  不随无关块重推）；拖拽排序手测路径文档化。
- Remote 预算降级的分级单测（22K 预算四级裁剪的纯逻辑进 tests/run.sh）。

**P1**

  修过一轮，重组后复测）。
- 诊断导出补远程链路摘要（最近快照尺寸/推送失败计数——32KB 修复的可观测面）。

**验收**：七阶段全绿 + 白板/远程桥回归（wb5/wb6 fixture）全过 + 产品页版本四处同步。

## 0.6.2 — Agent 闭环

**P0**
- **回合检查点/恢复 v1**：每轮工具执行后落检查点（会话文件已有消息落盘，补"运行
  状态"：进行中工具批、压缩预算覆盖）；app 崩溃/强杀后重开会话可从最后检查点
  继续（对话框显式提供，不自动跑）。验收：强杀 → 重开 → 继续 → 轨迹连续可导出。
- **旁路成本归账**：crew/critic/标题/记忆整理的 token 记到会话（挂消息或会话级
  汇总字段），成本页区分"主回合/旁路"。验收：一次含标题生成与 crew 的回合，
  `GET /agent/stats` 总量 = 主回合 + 旁路。
- **成本感知路由 v1**：偏好里可选"旁路调用用便宜模型"（默认关）；标题/记忆整理
  走指定档。验收：假端点断言旁路请求的 model 字段。
- **多窗口 Agent 联动 v1**：面板跟随前台窗口（deliveryTarget 已跟随，补跨窗会话
  列表与"在新窗口打开此会话"）。验收：双窗口各自会话互不串台（桥断言）。

**P1**
- **向量记忆 spike**：`NLEmbedding` 端上句向量 × BM25 混合检索；先验证 zh-Hans
  支持质量（对照集 20 条），可行则进 0.7，不可行文档写明结论。
- 评估集扩面：白板工具契约（get/edit/insert/move 错误分支）进 agent-eval。

**依赖/风险**：检查点与 DiskStore 500ms 防抖的交互（强杀丢写窗口）——检查点写
走同步路径；多窗口联动与"面板单例"假设的冲突面（WhiteboardPanel 等单例面板要跟）。

## 0.6.3 — 跨设备一致

**P0**
- **白板同步域（第九类）**：`whiteboard` 域进 sync（块为结构化 JSON，E2E 套路
  现成：FlatSyncMerge/墓碑/游标）；类目开关默认**关**（板属个人创作，默认仅本机）。
  验收：双设备 curl 直推 + 客户端合并断言；tombstone 语义与既有八类一致。
- **Remote 完成通知**：Agent 回合结束且手机端页面不在前台 → iOS 本地通知
  （app 被杀收不到是平台事实，快照通道在线即触发；不承诺推送）。
- **Remote 长会话不哑**：快照分帧拉取（控制器按需拉更早消息，32KB 预算内分页）。
  验收：200 条消息会话在手机端可上翻到头。

**P1**
- **同步诊断页**：设置 → Sync 增加"同步日志"（逐域最近成功/失败/冲突计数，
  LWW 输掉给条目级提示）。验收：人为制造冲突可见。
- 历史 tombstone 客户端 GC：本地 500 条滚动淘汰时对已同步条目落墓碑的内存占用
  收口（已有语义，补上限与诊断）。

**依赖/风险**：白板同步与"板属用户"边界——页面仍无权写（spec §5.1 不变）；
iOS 本地通知权限要懒请求（TCC 纪律）。

## 0.6.4 — 页面控制

**Spike 先行（0.6.4 第一周，结论写进 docs/）**
- WebKit 下"真拦截"的可行域盘点：WKContentRuleList 的 redirect/header 动作边界、
  进程内代理（需信任 CA，侵入性高）、`URLSchemeHandler` 适用面。**结论驱动交付，
  不做假 UI**（网络节流若无真实现路径就明说"模拟"并标注）。

**P0（按 spike 结论裁剪）**
- **ContentRuleList 动态封装 v2**：现有规则引擎加"会话级动态规则"（Agent/用户
  临时拦截某域、重定向某 URL，随标签页生命周期销毁）；桥端点可驱动。
  验收：fixture 页断言请求被拦/被重定向，规则随标签关闭清除。
- **Agent 工具**：`networkRules`（add/clear/list，risk=sideEffect 进审批）；
  与 DPP `ignore`/`blockElements` 的关系文档化。
- **响应式收尾**：pixelRatio 模拟（JS 层 `devicePixelRatio` 覆盖 + 截图元数据
  一致性）；真节流若 spike 判定不可行，UI 文案改"加载节流（模拟）"并去重。

**P1**
- DevTools Network 页签加"动态规则"入口（右键请求 → 拦截/重定向）。

**依赖/风险**：WebKit 每版行为漂移（全屏/VisionKit 前车之鉴）——所有拦截能力
默认关、按站点开；与视频广告拦截规则的热插拔代数机制兼容。

## 0.6.5 — 生态可发现

**P0**
- **DPP 逐动作审批**：审批策略支持 per-(host, action) 记忆（"本站此动作始终允许"），
  与现有三级访问等级正交。验收：同站 A 动作免批、B 动作仍逐次。
- **DPP 检查器**：DevTools 增加页签——当前页声明树（views/actions/events）、
  最近解析与事件流、逐字段命中选择器高亮。验收：demo 商店页逐视图可展开。
- **白板单文件分享**：导出独立 HTML viewer（单文件内联块数据 + 按需提示加载
  vendored 引擎或离线降级为静态文本）。验收：导出文件双击在无 Desire 机器可读。
- **跨源 iframe**：DPP 声明穿透跨源 iframe（同源已有）——按 spike 结论，可能
  仅支持"声明式透传"（iframe 页自声明 + 宿主聚合）。

**P1**
- **首启引导**：三步（选模型：端上一键 / 填 key；开拦截默认档；配同步可选），
  每步可跳过；完成后落一个样例会话。
- DPP 文档站（website/dpp/：规范速览 + SDK 三行接入 + 在线校验器）。

## 明确不做（0.6.x 内，含既定决策）

- **Web Push**：WebKit SPI 无公开路径（实测过，不再投入）。
- **白板自由画画**：白板 = 结构化数据渲染器的定位不变（自由画是无边记的活）。
- **内置 ffmpeg / yt-dlp**：外挂探测模式不变（Homebrew 路径探测；yt-dlp 同款
  待评估，不打包）。
- **重开 App Sandbox**：Agent 需要系统级执行能力，安全边界 = Hardened Runtime
  + 审批策略（AGENTS.md 立规）。
- **默认遥测/崩溃上报**：无用户许可不上传任何数据；诊断靠本地导出。
- **服务端全文检索**：E2E 加密下服务器不可见明文，检索只在端上。
- **DASH 直连**：Homebrew ffmpeg 无 dash demuxer（实测），不裸写 demuxer。

## 质量门（每版通用，延续既有纪律）

1. `xcodebuild clean build` 零警告（路径在 `warning:` 之前——grep 口径用
   `grep -E "warning:"`，增量构建不算数）；iOS 侧同口径。
2. `tests/run.sh` 全过（新增纯逻辑必须进 harness）；agent-eval 全过。
3. 发版只走 `scripts/release.sh`（七阶段）；CHANGELOG 条目随对应 fix 提交、
   只用 changelog.py。
4. 性能预算：冷启动 ≤700ms（基线 632ms）；流式 40KB 回答面板可交互（主线程
   卡死计数 0）。
5. 三语：新文案三键齐（zh-Hans 可键名回退，en/zh-Hant 必须显式）。
6. 安全复核：新工具面必须过审批策略矩阵（readonly/sideEffect/dangerous 定级）、
   新同步域必须 E2E 加密 + 墓碑语义。
7. 用户实测收口：UI 交付必须真截图目视（chip 吞卡的教训——数据链路绿 ≠ 看得见）。
