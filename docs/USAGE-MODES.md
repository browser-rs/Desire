# 使用模式速查

Desire 有三种使用模式（菜单 **Mode** 或 `⌃⌘1/2/3`，也可在 设置 → 使用模式 切换）：

| | Agent 工作台 | 纯浏览器 | 混合 |
|---|---|---|---|
| 界面 | 单窗：对话 + 目的地侧栏 + 可折叠浏览面板 | 标签栏 + 页面 + Agent 侧栏 | 用户窗口 + Agent 窗口 |
| 浏览器在哪 | 面板里（折叠时在后台运行） | 你的窗口 | Agent 自己的窗口 |
| Agent 操作对象 | 面板自己的标签 | 当前窗口 | 默认 Agent 窗口 |
| 隔离 | Agent 专属容器 | 你的档案 | Agent 专属容器 |
| 打扰方式 | 面板就地展开（Peek） | 侧栏/浮窗 | 非激活浮层，点击才激活 |

## Agent 工作台

- 对话为主界面；点「显示浏览器」展开内嵌面板（地址栏、前进后退、刷新、标签）。
- 面板**折叠时仍在后台运行**：Agent 能继续导航/读页面/执行 JS；需要你登录或确认时，
  工作台会弹出 **Peek 横幅**并展开面板，处理完点「完成」——Agent 会收到"页面是否变化"的备注。
- 你在面板里操作期间，Agent 的工具对该面板暂停（接管锁），不会和你抢。
- 关掉最后一扇窗口会**自动切回纯浏览器**，避免下次启动"浏览器不见了"。

## 纯浏览器

就是你熟悉的形态：Agent 在侧栏/浮窗里协作，工具作用于当前窗口。适合边看边问。

## 混合（互不干扰）

- 两个完整窗口：你的浏览窗口 + **Agent 窗口**（标题「Agent 工作台」）。
- Agent 默认只动自己的窗口；你要它动你的窗口，需要明确说，并且危险动作会走审批。
- 菜单 **Mode → 并排显示** 可把两窗平铺左右；各自保留标签与焦点。
- Agent 需要你时，右上角出现**非激活浮层**（页面快照 + 原因）；点「去处理」才切到
  Agent 窗口，不打断你正在打的字。

## 登录态（重要取舍）

设置 → 使用模式 → 登录态：

- **默认：隔离容器**。Agent 有自己的 cookie 空间，看不到你的登录态；需要登录的站点
  在 Agent 窗口里登录一次即可（之后长期有效）。
- **沿用当前登录态**：Agent 直接用本机档案，便利但隔离性更弱（打开前会二次确认）。
- 也可以只搬 **cookies** 到隔离容器（`POST /cookies/seed`）：登录态快照，但
  localStorage / IndexedDB 不迁移，部分站点仍会要求重登。
- 一次性、不可信的页面用 `POST /page/read-ephemeral` 读：内存会话，读完即弃。

## 常见问题

- **Agent 说"surface is being used by the user"**：你正在接管那个浏览面。点 Peek 的
  「完成」或关掉浮层即可恢复。
- **混合模式没有 Agent 窗口**：菜单 **Mode → 打开 Agent 窗口**；关掉后角色会保留，
  重新打开会回到原会话。
- **切模式会打断正在跑的回合吗**：不会。工具面在回合结束后才切换。
- **重启后窗口不对**：模式与窗口角色都落盘；混合模式会按角色恢复两扇窗，专注模式
  只开工作台。
