论坛演示的治理后台：对论坛的真实帖子做隐藏/恢复与删除。教学重点是 danger: true 动作——「删除帖子」声明了 danger，即使访问等级开到自动编辑， 每一次执行都会请求批准（danger 是最高闸门）。对智能体说：

  • 「看看有哪些帖子」→ pageExtract("mods")（hidden 是布尔字段）
  • 「把 3 号帖隐藏掉」→ pageAction("toggle-hidden", …)（论坛页随之不可见）
  • 「删掉 3 号帖」→ pageAction("delete-post", …)——danger 动作，必弹审批卡
这是一个用 data-dpp-ignore 标注的假广告横幅（智能体会忽略这里）
