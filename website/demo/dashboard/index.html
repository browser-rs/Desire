一个聚合看板：指标来自其他演示场景的真实数据（商店订单、预约、IM 消息、论坛帖子），每 5 秒刷新。 演示重点是 busy / error 信号与数据变化事件——对智能体说：

  • 「看板现在什么情况」→ pageExtract("metrics")（数值是数字）
  • 点下面「模拟服务降级」→ 页面出现 error 信号，智能体读状态时会看到「服务异常」
  • 去别的演示页下个单/发个帖 → 回到这里数据变化触发 stats-updated
  • 「把看板数据画成柱状图」→ 智能体 pageExtract("metrics") 取数后用 whiteboard 工具可视化（宿主内置白板，声明 views 即可被提取渲染）
