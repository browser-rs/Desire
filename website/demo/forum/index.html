DPP 论坛演示 连接中…

一个由演示 API 驱动的迷你论坛：发帖、点赞（可取消）、评论，数据落演示服务的共享库。 对 Desire 智能体说：

  • 「看看论坛上有什么帖子」→ pageExtract("posts")（点赞/评论数是数字）
  • 「发个帖子标题 X 内容 Y」→ pageAction("new-post", …)（effects: "outbound"，会先请求批准）
  • 「给 1 号帖子点赞，再评论一句写得好」→ like-post / comment（sku 式选择器模板）
  • 有新帖或互动发生 → forum-activity 事件唤醒智能体
这是一个用 data-dpp-ignore 标注的假广告横幅（智能体会忽略这里）
