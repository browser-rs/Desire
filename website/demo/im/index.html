DPP IM 演示 连接中…

一个由演示 API 驱动的精简即时消息页：两个频道、两个脚本机器人。 消息落库（服务是多实例部署，状态共享），页面对 Desire 智能体的价值在于 message-received 事件驱动——新消息到达会自动唤起智能体。试试对智能体说：

  • 「看看客服频道有什么新消息」→ pageExtract("messages") 读消息列表
  • 「切到招聘频道，跟机器人走一遍流程」→ pageAction("open-channel", …) + send-message
  • 「有人找我吗？有就回复他」→ 新消息的 message-received 事件会先唤醒智能体
这是一个用 data-dpp-ignore 标注的假广告横幅（智能体会忽略这里）
