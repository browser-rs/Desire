DPP 演示商店 连接中…

本页是一个按 Desire Page Protocol 接入、由演示 API 驱动的迷你商店： 购物车与下单是真实请求（写入演示服务的内存，非真实交易）。用 Desire 打开，对智能体说：

  • 「列出商品」→ pageExtract("products") 读结构化数据（价格转数字、SKU 可用于加购）
  • 「把 sku 是 kb-01 的商品加入购物车，再来一把」→ pageAction("add-to-cart", …)
  • 「去结算」→ pageAction("checkout")——该动作声明了 effects: "outbound"，会先向你请求批准（审批流演示）
  • 下单成功的那一刻 → 订单列表出现新行，order-placed 事件自动唤起智能体（事件驱动演示）

本页声明通过 L3 SDK 的 desire.expose() 提供； 右下角虚线框是噪音区，智能体会绕开。
