Desire Browser · AI agent browser for macOS

The browser that does
the work.

Desire Browser — also called Desire Agent Browser — is a native macOS browser with an AI agent built into the browser itself. It reads the page, clicks, types, runs commands, checks its own work and reports back. Not a chatbot in a sidebar: the agent is the user, and the page is its workspace.

An agent browser, not a browser with a chat box

Most "AI browsers" put a text field next to the page and hope the model can describe what to click. Desire gives the agent the same channels a person has: it reads text, HTML, the DOM tree, screenshots and the network log; it clicks, types, scrolls, fills forms and uploads files; and every side effect passes an approval policy you set.

100+ TOOLS

Real browser tools

Navigation, page reading, element refs, waits, form filling, uploads, downloads, captures, history, bookmarks, zoom, reader mode, PiP and an escape hatch to JavaScript and shell commands.

CONTROL

Approvals you own

Three access levels: confirm before every side effect (default), auto-edit page operations while commands stay gated, or full access. Command allow-lists are separate.

LONG HORIZON

Plans, memory, skills

A live checklist, mid-task questions, persistent memory per profile, reusable skills, subagents, scheduled tasks and a trace of every step with tokens and cost.

INTEROP

MCP and automation

Connect MCP servers, or drive the browser from your own agents through the MCP server and a 60+ endpoint local automation bridge.

What else a browser should not be missing

Office without leaving the tab

A whiteboard for structured output

Your data stays yours

There is no account requirement for local features. When you turn on multi-device sync, bookmarks, settings, memory and the other synced domains are encrypted on this Mac before upload — AES-256-GCM with keys derived from your password. The server stores ciphertext and cannot read your items.

  • Bring your own model key — OpenAI-compatible, Anthropic, local Ollama, or Apple on-device models.
  • Chat history stays on the Mac by default; it is not part of sync.
  • Model requests go to the provider you configured, not to us.
  • Everything above is open source: github.com/browser-rs/Desire.

Frequently asked questions

Is Desire Browser the same as Desire Agent Browser?

Yes. Desire is the product name; Desire Browser, Desire Agent Browser and Desire AI Browser all refer to the same macOS AI agent browser. The source repository is github.com/browser-rs/Desire.

What makes Desire an AI agent browser?

The agent is not a chat sidebar. It sees the page like a user (text, HTML, DOM tree, screenshots, network log), acts like a user (click, type, scroll, fill, upload), and every side effect passes an approval policy. It runs 100+ real browser tools, keeps plans, memory and skills, and records a full trace with token usage and cost.

Is Desire Browser free?

Yes. All features are free; installers are published on GitHub Releases. No account is required for local features — an account only appears when you enable multi-device sync.

What are the system requirements?

Apple Silicon (arm64) or Intel (x86_64) Mac running macOS 26.5 or later. The Intel build is cross-compiled and not verified on physical Intel hardware.

Is Desire built on Chromium?

No. Desire is a native SwiftUI app using Apple's WebKit (WKWebView), not Chromium. It supports mainstream Chrome MV3 extension capabilities through its own plugin runtime.

Which AI models can I use?

Bring your own key (BYOK): any OpenAI-compatible endpoint, Anthropic Messages API, a local Ollama server, or Apple's on-device Foundation Models. Each provider profile stores its own endpoint, key, model list and extra headers.

Does sync expose my data to the server?

No. Bookmarks, settings, memory and other synced domains are encrypted on-device before upload (AES-256-GCM with keys derived from your password). The server stores ciphertext only.

The app says it is damaged or cannot be verified. What do I do?

Desire is an unsigned build (no Developer ID certificate). After moving Desire.app into Applications, run xattr -cr /Applications/Desire.app once in Terminal to remove the quarantine flag.
