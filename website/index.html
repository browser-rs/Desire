Desire 为干活而生：页面是你的，数据是你的，替你动手的智能体也在你的机器上。 不注册账号，也能用尽每一项本地功能； 想要多设备同步时，账号、验证码与端到端加密都已备好。

六件正事

一台浏览器该有的，与不该缺席的。

01

AI 智能体，侧栏浮窗随心放

停靠在侧栏，或拖出去成独立小窗——边浏览边盯着它干活。 读页面、执行 JavaScript、跑 shell 命令、派子代理分头干活；多窗口各管各的标签， 还能让它跨窗口操作。做完一件事，从轨迹到耗时逐条可查；浏览器意外退出， 被打断的回合能原地继续。记忆分画像、事实与摘要，按相关度检索后注入对话； 输出规则、人设、每会话指令随你定，点踩的回答沉淀为反馈记忆——默认留在本机。

02

端到端加密的八类同步

书签树、快速拨号、阅读列表、快捷键、设置、Agent 记忆、提示词与浏览历史， 八类数据逐项可选（浏览历史默认关闭）。密钥由你的密码派生，服务器只见密文；注册与登录有图形验证码把关。

03

视频站，清净且能带走

视频广告按站点规则拦截，规则热插拔、无需更新应用； 想收藏的 HLS 视频直下 MP4——本机装有 ffmpeg 便自动直连，音轨一个不丢； 整个列表页可以拉成批量任务：指定目录与并发、智能分卷、断点续传、 磁盘空间预留，失败自动重试；同名文件按你的设置重命名或覆盖。

04

广告与追踪，拦得明明白白

内置 EasyList / EasyList China 转换规则，兼容自定义规则语法； AI Auto-Clean 还会在页面加载时自动识别广告元素并拦截——拦了什么有 toast 告知， 你拆掉一条该站就豁免，规则随时可回滚。

多档案与效率

工作与生活分属不同档案，Cookie、历史、书签互不掺杂； 快速拨号、阅读列表、查找栏、会话恢复，外加一套能改到每一个键的快捷键。

网页协议 · DPP

让网页主动向 AI 交代自己。

Desire 定义了一套开放协议（Desire Page Protocol）：页面用几行声明讲清 我有什么数据、能做什么、何时就绪——智能体按声明精准读写， 不再靠猜选择器、不再误读噪音。四级接入，从零改造到一行 SDK； 任何 Agent 都可消费，不限 Desire。

L0 · 零改造

既有标记直接消费

页面已有的 JSON-LD（Product / Article 等）自动成为结构化视图，站点一行代码都不用写。

L1 · 属性微标注

data-dpp-* 属性

在现有 HTML 上标注视图与字段，扫描即编译；噪音区域标 data-dpp-ignore，智能体绕着走。

L2 · 声明块

一段 JSON 讲清全页

<script type="application/x-desire+json"> 集中声明视图、信号、动作与事件，SSR 站点改模板即可。

L3 · 官方 SDK

一行 expose

引入 desire-sdk.js，desire.expose({...}) 即完成声明；SPA 路由变化自动重声明，事件精确发射。

<script src="desire.mankong.icu/desire-sdk.js">
desire.expose({ views: { products: {
　item: ".card", fields: { title: "h3" } } },
　signals: { ready: "[data-app-ready]" },
　actions: [{ name: "add-to-cart" }] });
</script>
智能体随即 pageExtract / pageAction ✓

穿透与站点级声明

选择器支持 shadow DOM 穿透（>>> 语法）与同源 iframe； 站点级 /.well-known/desire.json 一次声明全站生效，页面级覆盖细节。

事件驱动

页面声明事件（新消息到达、审批就绪），DOM 出现即自动唤起智能体—— 监控型站点从此"网页开口，AI 接活"。

声明能力 ≠ 授权

站点把动作标为对外不可逆（outbound / danger），Desire 强制逐次审批—— 协议说能力，授权始终在你。

端到端加密同步

服务器被整个搬走，
读到的也只有密文。

密码只属于你

注册那刻，密码在本机经 PBKDF2 · 600,000 轮派生出包裹密钥——明文密码从不离开这台 Mac。

数据密钥被包裹托管

一把 256 位随机密钥负责加密数据；它被包裹密钥锁好后才存到服务器，换设备登录即自动恢复。

每类数据各用各的钥匙

八类同步各自派生独立密钥，条目 ID 一律换成不可逆标签——服务器连"哪条属于哪条"都数不清。

书签树 快速拨号 阅读列表 快捷键 设置 Agent 记忆 Agent 提示词 浏览历史 · 默认关 AI 对话 · 永留本地

诚实起见：服务器仍能看到账号、类别、行数与时间这类元数据。 改密码不会弄丢既有数据——同一把密钥用新密码重新包裹；忘记密码则密文不可解，这是端到端加密的标准取舍。

常见问题

问得最多的事。

Desire 是免费的吗？

是。全部功能免费使用，安装包从 GitHub Releases 下载。无需注册即可使用所有本地功能——账号只在你需要多设备同步时才出现。

需要什么硬件和系统版本？

Apple Silicon（arm64）Mac，macOS 26.5 及以上版本。

打开时提示无法验证或“已损坏”怎么办？

Desire 是未签名构建（没有 Developer ID 证书）。把 Desire.app 拖进「应用程序」后，在终端执行一次 xattr -cr /Applications/Desire.app 移除隔离标记，即可正常打开。

AI 用什么模型？要额外付费吗？

模型自带（BYOK）：任何 OpenAI 兼容服务、Anthropic 官方或同方言网关、本机 Ollama、macOS 端上模型都能接。思考等级可调，token 用量与成本按你填的单价在本机核算；模型服务本身的费用由各服务商收取。

同步的数据安全吗？服务器能看到我的书签吗？

看不到。同步是端到端加密的：密钥由你的密码在本机派生（PBKDF2 六十万轮），八类数据（浏览历史默认关闭）加密后才上传，服务器只见密文，连条目 ID 都换成了不可逆标签。AI 对话永久保留在设备本地，不参与同步。

能批量下载视频吗？

能。把列表页拉成批量任务：逐个嗅探或逐页解析，可指定保存目录与并发数，支持断点续传、磁盘空间预留与失败自动重试；遇到人机验证会请你人工过一次，之后同批自动继续。

支持 Chrome 扩展吗？

支持主流 MV3 扩展的能力面：内容脚本、后台页、popup、消息互通（含长连接）、declarativeNetRequest 动态规则（映射到原生拦截引擎）、脚本动态注入、右键菜单、工具栏角标、本地化与定时器。可从文件夹直接装载，也认 .msex、zip 与 Safari 扩展包；少数依赖 Chrome 私有能力（如阻塞式 webRequest）的扩展暂不可用。

支持 iPhone 吗？

完整浏览器是 macOS 应用；iPhone 上有 Desire Remote——扫码配对后可以远程驱动 Mac 上正在运行的智能体：发消息、看进度、管理会话。

智能体会不会乱执行命令？

访问等级三级可调：变更前确认（默认，副作用逐次审批）/ 自动编辑（页面编辑自动通过，系统命令仍管控）/ 完全访问（全部静默）。系统命令另有命令级允许列表——未授权命令会主动向你申请，批准一次永久生效。

忘记同步密码会怎样？

解密密钥由密码派生，密码遗失则服务端密文不可解——这是端到端加密的标准取舍。修改密码不会丢数据：同一把密钥会用新密码重新包裹。

什么是 DPP？我的网站怎么接入？

DPP（Desire Page Protocol）是 Desire 的开放页面协议：网站声明自己有什么数据、能做什么、何时就绪，智能体按声明精准读写，不再靠猜。接入分四级——已有 JSON-LD 零改造自动消费、HTML 加 data-dpp-* 属性、script 声明块，或一行引入官方 SDK（desire.mankong.icu/desire-sdk.js）；规范见仓库 docs/DPP-PROTOCOL.md。声明能力不等于授权，对外动作仍逐次审批。

智能体的记忆和个性化是怎样的？

记忆分画像、事实与摘要三类，按相关度检索后注入对话，默认留在本机；可设输出规则、人设与每会话指令，点踩的回答会沉淀为反馈记忆。全部可编辑、可一键清空。
